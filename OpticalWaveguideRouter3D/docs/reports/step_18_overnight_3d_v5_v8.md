### 1.4 采纳结论

### 1.5 状态类别口径限制

UU/UE/EE 只是**可达性代理**：它只说明双方当前的抬升状态，不说明哪一侧存在合法生成窗口。
实测 EE 类别多次出现“双方都无合法窗口”（挑战起点尤甚），UE 也可能只有一侧可动；
因此本文不把类别写成“生成能力类别”。
## 二、v6 候选评价调度

指定变更：只改候选评价政策，目标调度、候选生成、候选池、廉价排序公式、胜者排名与验收标准全部保持。

- **E0 LEGACY_EXHAUSTIVE**：沿用原候选顺序，尽可能评价本目标所有允许候选（等于已采纳的 v5 LEGACY 配置）。
- **E1 ORDERED_EXHAUSTIVE**：跨 victim 合并全部候选，用固定廉价估计排序后**仍然评价全部**。
- **E2 ORDERED_K16**：与 E1 完全相同的候选池与排序，但每个目标两侧合计最多评价 16 个；固定 K=16。

廉价估计（正式评价前冻结，见 src/overnight_engine_3d.py 的 cheap_candidate_score）：
(对侧当前冲突度数的负值, 候选额外长度, 高段长度, 目标层, 升窗, 降窗, victim_id, 候选序号)。
它只使用生成时已知的信息，不使用真实净减少，也不额外扫邻居。

manifest/round_v6.json 的 SHA256 为 bf1dc5d92a8dad5fa2463aebbc67b331e779e276961420be79738bbfa8dc6848。

### 2.1 E0 与 E1 逐位一致：排序本身没有改变结果

outputs/overnight_3d_ideas/equiv/v6_e0_vs_e1.json：三档预算 × N/R 共 6 个单元，E0 与 E1 在终态近距对、
动作数、阶段长度、过渡结构数、步级轨迹与终态近距集合 SHA256 上**全部一致**（all_identical=true）。
因此本次 E0 到 E1 的差异来自**预算边界**而不是排序：目标候选数有限、预算也够时，两种顺序都会把候选评完，
胜者由 strategy_rank 决定，与评价顺序无关。

1. **E2 在每个预算上都大幅降低终态近距对**：720 减少 6,334（15.8%）、1440 减少 10,558（28.5%）、
   2880 R 减少 11,766（38.0%）、N 减少 12,555（40.5%）。代价是同预算下阶段长度从 23.78 mm 增到 57.50 mm，

2. **评价/动作从 54 到 65 降到 16 到 19**，净减少/评价从 3.9 到 4.1 升到 8.2 到 12.7：减少同一目标大量评价
   却只执行一个动作的浪费，确实换来了更多有效动作（53 增到 161 个动作）。
3. **K 截断确实会漏掉更好的候选**。在冻结诊断集（v4 审计的 120 个目标侧，评价前冻结）上，
   基础评价 2,781 次、完整验收 2,583 次（与 v4 审计完全相同的计数），87 个侧有可测数据、86 个侧存在可完整通过候选；
   其中 **75 个侧**的 K16 前缀胜者严格差于完整枚举胜者，合计净收益 14,972 对 vs 完整枚举 17,551 对，
   前缀在固定诊断集上少拿 2,579 对（14.7%）。这不是全板最优性结论，只说明截断有代价；全板结果仍然更好，
   是因为同预算下执行的动作数多了一个数量级。
4. **未评价不计为失败**：E2 在 2880 上把 7,313 个候选标为 PER_TARGET_K_PREFIX、13 个标为
   CANDIDATE_BUDGET_EXHAUSTED，ALL_CANDIDATES_REJECTED 为 0；前缀无胜者且仍有未评候选时记为
   PREFIX_EVALUATED_NO_WINNER_DEFERRED 并在布局版本变化后重试（2880 上 21 次），不写入全部失败缓存。
5. **本轮的 N/R 差异不是重定位的证据**：E2 的 N 与 R 都执行了 **0 次重定位**（LEGACY 目标序从不选中只有重定位
   可动的目标）。两者数值不同只因为 R 让已抬升 victim 也进入候选池，改变了廉价排序与 K16 前缀的内容。
   任何把 E2 的 N/R 差异解释成重定位收益的说法都不成立。
6. **目标上限在挑战起点上确实是约束**：E2 的两个挑战组都在 max_targets=200 用尽时停止（仅用 2,353 / 2,481 次评价），
   主试验 2880 上则用满预算。这直接构成 v7 的实验动机。

预声明规则：正确性与复核全部 PASS；主试验 R2880 终态近距对 E2 19,233 小于 E1 30,999 等于 E0 30,999，

## 三、v7 目标覆盖与遍历

指定变更：只改目标尝试上限与遍历规则；候选生成、廉价排序、每目标 K=16 配额、胜者排名与验收标准保持。

- **T0 BASE_200**：max_targets=200（= v6 采纳的 E2 配置）。
- **T1 BASE_2000**：同一遍历，只把上限提到 2000。
- **T2 COVERAGE_2000**：max_targets=2000 且使用预先固定的覆盖遍历：在既有状态分层内优先处理**最久未被触达的路线**，
  同档用原 target_priority 决胜；并启用按布局版本失效的结构性跳过集合（只影响跳过事件的重复记录，不改变结果）。

口径（结果中实际使用的字段）：`target_attempts` = 步骤数（含零候选与中断步骤），不等于唯一目标数；
`unique_target_pairs` / `unique_target_sides` / `unique_routes_evaluated` / `repeated_target_attempts` /
`max_attempts_on_one_route` 均为独立计数；`TARGET_LIMIT` 与 `CANDIDATE_BUDGET_EXHAUSTED` 是两种不同终止原因。

### 3.2 三个必须分开回答的问题

**1. 上限在哪里真的触发？** 主试验上从未触发：T0 与 T1 在三档预算 × N/R 的六个单元上**逐位一致**
（终态近距对、动作数、阶段长度、过渡结构数全部相同）。T0 在主试验 2880 的实际目标尝试为 190 < 200，
终止原因是预算用尽。只有在挑战起点上，T0 两个组都在 200 次尝试时停止且仍剩 527 / 399 次评价没用完，
此时提高上限才有效。因此“提高上限”在 v4/v5 主起点上没有作用，这一点是明确结论而不是未测到。

**2. T0→T1 的收益**：主试验 = 0（逐位一致）；挑战起点 = 近距对 15,837→14,583（N，−1,254）与
16,537→16,285（R，−252），代价是阶段长度由 41.199632 增到 52.097327 mm（N）。
**3. T1→T2 的收益**：全部为负。主试验 720 +153、1440 +2,507、2880 N +5,570 / R +5,152；
挑战 +4,185（N）/ +3,183（R）。覆盖遍历确实扩大了广度（唯一路线 163→231，单路线最多尝试 104→5），
但它把预算从高收益目标转移到低收益目标，净效果显著变差。因此**不采纳覆盖遍历**。

### 3.3 采纳结论

预声明规则：正确性与复核全部 PASS；主试验 R2880 R 终态近距对 T0 = T1 = 19,233，T2 = 24,385 被淘汰；
T0 与 T1 在近距对、阶段长度、实际评价数上完全并列，按规则最后一步**保留旧配置**（T0 = v6 的 LEGACY + E2）。
v7/adoption.json 记录了 `retained_old_config=true`；其中 `target_policy/evaluation_policy` 两个字段在“不采纳”
分支会回落到注册表默认值，**不是**当前生效配置，正确语义见 v7/adoption_note.json。
## 四、八项机制单项消融

共同基线（BASE）= v6 采纳的 LEGACY + E2_ORDERED_K16（K=16、max_targets=200）。
每个机制只改一个指定因素，其余全部保持一致；BASE 的六行是 v6 E2 组带来源与 SHA256 的逐字复制引用。
所有组均通过终态保存→重载→130,816 对全扫复核。

| 机制 | 720 N | 720 R | 1440 N | 1440 R | 2880 N | 2880 R | 与 BASE 相比 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| BASE（对照） | 33,738 | 33,738 | 26,437 | 26,437 | 18,444 | 19,233 | — |
| A 候选家族轮询 | **33,529** | **33,529** | **25,187** | **25,187** | **17,905** | **18,459** | 每个预算都更少 |
| B 重定位配额预留 | 33,738 | 33,738 | 26,437 | 26,437 | 18,444 | 19,233 | 逐位相同，无效果 |
| C 目标等待年龄 | 33,738 | 33,738 | 26,437 | 26,437 | 18,444 | 19,233 | 逐位相同，无效果 |
| E 多目标锚点 | 32,565 | 32,565 | 32,565 | 32,565 | 32,565 | 32,565 | 720 略好但 1440/2880 大幅退化 |
| F 精确几何去重 | 33,738 | 33,738 | 26,437 | 26,437 | 18,444 | 19,233 | 逐位相同，无效果 |
| G 判定缓存 | 33,738 | 33,738 | 26,437 | 26,437 | 18,444 | 19,233 | 逐位相同（要求如此） |
| H 撤回冻结平面 | 33,738 | 33,738 | 26,437 | 26,437 | 18,444 | 19,233 | 逐位相同，无效果 |

### 4.1 A 候选家族多样性：唯一一个在每个预算上都不退化的单项

在固定的 K=16 前缀内，按 (目标层, 升窗 primitive, 降窗 primitive) 家族做确定性轮询（家族顺序由各族最优廉价分决定），
与对照的统一廉价分 top-K 使用完全相同的候选池与总 K。

| 预算 | BASE 终态 | A 终态 | 差 | BASE 阶段长度 | A 阶段长度 | A 评价数/停止原因 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 720 N = R | 33,738 | 33,529 | −209 | 14.883191 | 22.265071 | 720 / 预算用尽 |
| 1440 N = R | 26,437 | 25,187 | −1,250 | 30.634838 | 45.452155 | 1,440 / 预算用尽 |
| 2880 N | 18,444 | 17,905 | −539 | 57.504186 | 71.863389 | 2,753 / 达目标上限 |
| 2880 R | 19,233 | 18,459 | −774 | 53.625801 | 69.234133 | 2,664 / 达目标上限 |

A 的代价是阶段长度明显增加（720 增加 7.38 mm、1440 增加 14.82 mm），过渡结构与已抬升路线也同步增加；
2880 上 A 在 200 次目标尝试处停止，仍有 127 / 216 次评价未使用，因此这一格不能与 BASE 的评价数直接对齐比较。
证据：结构化候选池没有变化，改变的只是“固定 K 里放哪些家族”——支持“统一分数 top-K 会被高度相似的升/降 primitive 家族占满”这一解释。

### 4.2 B、C、F、G、H：四个零效果与一个必须为零的结果

- **B 重定位配额预留**：预留 half-K 给已抬升一侧。三百六十个终态与 BASE **逐位相同**，重定位评价数仍为 0（R720/1440 为 0，R2880 为 112 次评价但 0 次执行）。
  原因明确：在 LEGACY 目标序下，只有重定位可动的目标从来不会被选中，所以“预留配额”预留不到任何东西。
  这同时说明：B 的假设在当前基线上**不可检验**，不是被否定。
- **C 目标等待年龄**：把排序主键换成确定性等待年龄。六个终态与 BASE 逐位相同。
  在 K=16 且目标上限尚未成为约束的主试验上，优先级排序已经不会长期饿死目标，年龄没有可改善的空间。
- **F 精确几何去重**：按完整几何指纹去重并剔除与当前路线完全相同的结构。`dedup_removed_duplicates = 0`、
  `dedup_removed_identical_to_current = 0`：本轮生成器没有产生任何完全相同的几何，因此没有可去重的内容。零效果来自输入事实，不是实现无效。
- **G 候选-邻居判定缓存**：键包含候选完整几何指纹、邻居 id、邻居路线版本号与 clearance。2880 上命中 223,440 次判定，
  六个终态与 BASE **逐位一致**（这是该机制的硬性要求）。它只减少判定调用，不改变任何结果，因此不主张净收益增加。
- **H 撤回冻结平面**：在 R 之上增加 RETURN 动作。2880 上构造了 7 个 RETURN 候选、评价了 7 个，**执行 0 次**；
  三类动作账本（首次抬升 / 重定位 / 撤回）分开记录，撤回一栏全为 0。因此“撤回能否带来额外净收益”在本轮**未测到**，
  而不能写成“撤回无效”——只能写成“在当前基线与预算下从未成为胜者”。

### 4.3 E 多目标锚点：720 略好、高预算大幅退化

给 victim 增加一个固定规则的当前冲突邻居 witness 锚点后，生成必须同时覆盖更多锚点，可行候选明显变少：
720/1440/2880 三档都在 **668 次评价**、200 次目标尝试处停止（TARGET_LIMIT），终态全部为 32,565 对。
720 上 32,565 优于 BASE 的 33,738（−1,173），但 1440 上劣于 26,437（+6,128），2880 上劣于 18,444（+14,121）。
机制本身并非“无效”，而是把目标尝试预算提前耗尽，无法把评价预算花出去。

### 4.4 D 路线覆盖调度：补充单因素对照后的混合结果

D 在 UU/UE/EE 分层内优先最久未被触达的路线。由于该规则**必须**在分层调度内部实施，而分层调度并未被 v5 采纳，
本轮额外预注册并运行了 `dctrl` 轮作为单因素对照：STRATIFIED + E2（与 D 完全相同的目标层与评价政策，
唯一差别是不启用覆盖遍历）。D 与它的对照放在一起才是单因素比较。

| 预算 | D（分层+覆盖） | D 对照（分层，无覆盖） | 差 |
| --- | ---: | ---: | ---: |
| 720 N | 34,083 | 34,006 | +77（更差） |
| 720 R | 37,039 | 39,408 | −2,369（更好） |
| 1440 N | 28,784 | 28,286 | +498（更差） |
| 1440 R | 32,764 | 36,520 | −3,756（更好） |
| 2880 N | 27,375（1,817 次评价，达目标上限） | 22,126（2,880 次评价，预算用尽） | +5,249（更差） |
| 2880 R | 30,092（2,185 次评价，达目标上限） | 30,864（2,880 次评价，预算用尽） | −772（更好） |

结论必须分 N/R 陈述：覆盖遍历在 R 形态下改善、在 N 形态下退化，且 2880 两格没有对齐评价数，
不能据此宣称覆盖遍历有效。同一规则在 v7 T2 上（在 LEGACY 目标序内、评价数对齐）是明确退化，
见第 3.2 节。**不采纳覆盖遍历。**

### 4.5 关于“组合策略”

任务要求“全部单项验证之后，可额外做一个清楚标注的组合策略，不把组合收益当成每个单项都有效”。
本轮只有 A 是可采纳的单项，B/C/F/G/H 为零效果、E/D 退化或混合，因此**没有做组合策略**：
把零效果项与退化项叠加不会有可归因的信息，只会产生一个无法解释的数字。这一点如实记录为未执行项。

### 5.4 运行期发现并修复的真实缺陷（保留记录）

## 六、本轮结论：什么得到支持、什么没测到、什么退化

### 6.1 得到支持

1. **候选评价配额（v6 E2，K=16）是本轮唯一在所有预算上都大幅改善的改动**：
   同预算终态近距对 40,072→33,738（720）、36,995→26,437（1440）、30,999→18,444/19,233（2880），
   评价/动作 54–65→16–19，已采纳。代价是阶段长度 23.78→57.50 mm、过渡结构 212→370、已抬升路线 77→185。
2. **重定位机制确实可达、可评价、可执行**（v5 的原始开放问题）：STRATIFIED 下 720 执行 1 次（净 −11）、
   1440 执行 3 次（净 −27）、2880 执行 6 次（净 −38）；LEGACY 下始终为 0 次，因为只有重定位可动的目标
   在共用优先序里排在两万名之后，从未被选中。这是调度可达性问题，不是几何或验收问题。
3. **主起点上 max_targets=200 不是约束**：T0 与 T1 逐位一致（六格），提高上限到 2000 没有任何作用；
   只有在固定挑战起点上上限才真的触发（stop=TARGET_LIMIT）。
4. **A 候选家族轮询是可复现的改善**：720/1440/2880 六个单元全部优于对照（−209 / −1,250 / −539 / −774），
   代价是阶段长度增加。
5. **G 判定缓存可以在结果逐位一致的前提下减少判定调用**：2880 命中 223,440 次，终态与对照完全相同。
   这是计算时间性质的结果，不主张净收益。

### 6.2 被否定或退化

1. **v5 STRATIFIED 未被采纳**：主试验 720/1440 明显更好（−1,188 / −738），但决定性的主试验 R2880 反而更差
   （33,343 vs 30,999），挑战起点 R 更差（+4,212）。EE 类别在高预算处占掉约三分之一目标尝试却几乎不产出，
   是退化的直接来源。挑战起点上 N 形态反而略好（20,421 vs 21,351）——方向不一致，必须分设置陈述。
2. **v7 覆盖遍历（T2）在评价数对齐时全面退化**：主试验 720 +153、1440 +2,507、2880 +5,152 至 +5,570，
   挑战 +3,183 至 +4,185。它确实扩大了覆盖面（唯一路线 163→231、单路线最多尝试 104→5），但没有换来收益。
3. **E 多目标锚点在高预算下大幅退化**：把目标尝试预算提前耗尽（668 次评价即达上限），
   1440/2880 终态 32,565 对，远差于对照。
4. **D 覆盖遍历在分层调度内是混合结果**：R 形态更好、N 形态更差，且 2880 两格没有对齐评价数，不构成有效性证据。

### 6.3 零效果（不是失败，也不是被否定）

- **B 重定位配额预留**：预留不到东西——基线的目标序从不选中只有重定位可动的目标，假设在当前基线上**不可检验**。
- **C 目标等待年龄**：目标没有被饿死，年龄没有可改善空间。
- **F 精确几何去重**：生成器没有产生任何完全相同的几何（去重数 0），没有可去重内容。
- **H 撤回冻结平面**：构造并评价了 RETURN 候选，但执行 0 次 → 收益**未测到**，不能写成无效。

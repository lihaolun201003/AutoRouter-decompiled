## 4. 式3-10—15逐式审计

以下按PDF正文15—16页转录：

```text
(3-10) gap = D - [r - sqrt(r² - (r-Dh)²)] >= d
(3-11) 0 >= Dh² - 2rDh + (r+d-D)²
(3-12) Dh >= r - sqrt(r² - (r+d-D)²)
(3-13) r < D + sqrt(2d(D-d))
(3-14) K = [r - sqrt(r² - (r+d-D)²)] / d
(3-15) K = [r - sqrt(r² - (r+d-|xt-xa|)²)] / d
```

【已确认】3-12分子表达要求的横向段分离距离下界；3-14除以长度d得到无量纲数。作者将其作为回看strip数量使用，不是把K当mm。但没有解释为什么3.1的strip宽w+d在此变为d，不能确定这是忽略w的近似、另一定义，还是笔误。

【合理推断：数学适用域】3-10根号要求 `0<=Dh<=2r`；实际90°弯曲构图还会限制适用分支。将3-10平方成3-11需注意 `r+d-D` 的符号：若其≤0，原不等式的根号下界已非正，不能仍机械平方为等价约束。3-12还选择了二次解的较小根；物理分支/上界没有写成程序规则。3-14实数要求 `|r+d-D|<=r`。大D时不可将负根号项任意clamp，也不能把式子在全域视为D越大K越小；单调性有分支限制。

【未确认】无邻居、无待布线端点、D越界、恰好等号、K超出网格等情况的前代处理。式3-13印为严格小于，前面若干约束是非严格不等号，未给数值容差策略。本次未计算或产生任何供allocator使用的K。

## 11. Pre-placement / post-routing接口关系（仅设计）

Legacy pre-check输入：候选strip、算法终止端弯曲、先前assigned路径/strip状态、K及窗口约定。输出：该候选可用/拒绝及证据。未通过不提交；通过后再提交。K不足以替代精确路径验证。

Exact post-check输入：最终完整SmoothedRoute2D集合；先取得PhysicalRouteIntersection，再保留完整pair multiplicity，检查三条路径。当前只有每对恰有一个cross的triplet进入legacy eligible判据；至少两条三角边严格小于spacing-tol才是multi，其余有boundary或outside_legacy_single_cross_assumption等状态。outside不是安全结论。

Exact candidate guard可共享同一数学判据，但需要临时**真实Line/Arc SmoothedRoute2D**。直角骨架只能用于构造，不能替代圆弧交点；只检查candidate和一条已有route也不足以证明三波导multi。

概念流程：构造临时candidate；计算它与已提交路径的全部physical events；结合已提交路径彼此的pair事件缓存，枚举包含candidate的triplet；沿用现有分类与容差；返回拒绝原因/triplet/交点或未覆盖状态；通过才提交几何和事件缓存。拒绝时不得污染正式状态。此处未新增接口或helper。

为保证局部筛选不会漏解，初版可比较candidate与全部已提交路径；若以后做相关路径筛选，必须证明保守覆盖。不能凭PMT邻接或K窗口裁掉可能相交的路径。最终仍需全量post-validation，以覆盖后续路径和special-Z。

## 12. Legacy K vs exact local guard

| 维度 | Legacy K | Exact geometry local guard |
|---|---|---|
| 前代忠实度 | 目标是复现，但当前关键语义缺失 | 沿用聚集目标与当前判据；明确不是复现旧K |
| 输入 | r/d/D、扫描及动态状态，部分未确定 | 当前候选Line/Arc与已提交完整几何可获得；需候选生命周期接入 |
| 复杂度 | 窗口扫描较小，但规则补全困难 | 事件缓存、三角枚举、临时提交管理较多；检测内核已有 |
| 数学确定性 | 公式有适用域、节距与离散化疑问 | 既有有限段及圆弧解析检测，受浮点tol和eligible范围限制 |
| 取整依赖 | 有，未确认 | 不依赖K取整 |
| 成本 | 固定K窗口通常更低 | 随候选数与已提交路径增长，三角枚举也有成本；不能承诺速度 |
| 未来价值 | 强依赖二维strip/终止bend模板 | 临时候选与检测分离可复用；现有二维交点定义不自动适用于3D |

【合理推断】exact方案目前工程确定性更好，原因是已有解析几何与一致判据，不是因为它“更新”。它可行不等于当前代码已经具备候选guard，也不等于覆盖所有交叉或清空间距问题。

### 1.1 间距计算修复（任务给定的反例）

R1 圆弧 A：圆心 (0,0)，30°→90°；R1 圆弧 B：圆心 (2.1,0)，160°→180°。

* 修复前：会给出 0.1（= 圆心距 − 两个半径，最近点根本不在弧上）；
* 修复后：**0.334005**（= B 的起点 (1.1603, 0.3420) 到 A 的起点 (0.8660, 0.5) 的距离），
  返回的两个最近点分别落在各自弧上、距离自洽、交换输入结果相同。

测试同时覆盖：直—弧相交（返回 0）、直—弧相切（返回 0 且分类为 touch）、
线线重合（返回 0 且分类为 overlap）、同心异径圆弧（返回半径差）。

### 1.2 允许交叉的排除规则（显式）

`spacing_report()` 的分类是：**cross = 允许的交叉**，由交叉事件系统单独统计损耗，
不计入间距违规；**touch**（相切/端点接触）与 **overlap**（共用轨迹）分别作为接触与
重合事件返回，不做静默忽略。只有"两条曲线不相交且中心线最小距离小于阈值"才计入
`SpacingViolation`。A/B/C/D 全部方案的 `overlap` 计数为 0，`touch` 为 0 或个位数。

## 2. 第二阶段：简单半径回退（D0）

D0 = 原版顺序 + 每个轨道上**优先尝试 R6、几何不可行才回退 R5** + 只取一个可行候选

## 3. 第三阶段：自由弯角 S 形路径

只用于跨上下两侧的连接，几何为

    直线引出段 + 圆弧(转角 α) + 斜向直线(长度 L) + 圆弧(转角 −α) + 直线引入段

端点切线仍垂直于板边（端口出线方向不变），连接身份与端点完全保持；半径首版限定
R5 / R6；同侧连接保留修复后的 U 型方案。

### 3.1 几何推导要点（与最初直觉相反的地方）

设 `sigma = sign(ly - sy)`、`s = sign(alpha)`、`Dx = lx - sx`、`dy = |ly - sy|`：

* 两段圆弧的**横向位移同向**（都等于 `R*sigma*s*(cos α − 1)`），而不是互相抵消；
  因此斜线必须同时消化"两弧的横向位移"与"端点横向差"：
  `L = (2*R*sigma*s*(cos α − 1) − Dx) / (sigma*sin α) ≥ 0`；
* 纵向：`S = t0 + t3 = dy − 2*R*s*sin α − L*cos α ≥ 0`，由 `t0_fraction` 分配；
* 由此得到两条硬约束：**终点在右（Dx>0）必须取 α<0，终点在左必须取 α>0**；
  **零水平偏移（Dx=0）在本路径族内无解**（横向位移与斜线同向，无法抵消），
  此时该连接必须回退到 U 型（`dx` 足够小时原版本身就是"两弧在中点相接"的 S 形）。

构造完成后自检端点、半径、切向连续与中间段长度；不满足即抛错，由调用方当非法候选
丢弃。候选网格 = {±5,±10,±20,±30,±45,±60,±75}° × {t0 占比 0,0.5,1} × 半径，
经几何合法性筛选后按"不含交叉的自损耗"取前 8 个再完整评分。

### 3.2 候选接受依据（不能只看弯曲损耗）

每个候选都要**重算自己与所有受影响既有路线**的：交叉损耗（真实切线角）、
接触数、重合数、间距违规数。**重合直接判定候选非法**；接触与间距违规按
`spacing_penalty_db`（默认 0，消融见 7.2）计入评分，避免"仅凭弯曲损耗降低就接受"。

### 3.3 求交的稳健性修补

既有 `src.collision` 的直—直求交对**一般方向**的直线会因绝对残差阈值抛
`Line intersection residual exceeds tolerance`（轴对齐直线不会触发）。Step 13 的
斜线暴露了这一点：`src/opt2d/intersections.py` 先调用既有实现，只在它因"残差"报错时
退回等价的稳健求解（改以中点为代表交点），其余异常照常抛出。256 全程只有 2 次、
512 极少次走该分支。

## 7. 敏感性分析

### 7.1 新增小角度交叉（交叉损耗表是数字化近似）

自由弯角引入了大量小角度交叉（256：<10° 从 0 个增到 153 个；512：从 3 个增到 842 个），
而交叉损耗表在这些角度上的绝对值本来就不可信。把 <20° 的交叉损耗整体乘以系数：

| 规模/方案 | ×0.5 平均 / 最大 | ×1.0 | ×2.0 |
| --- | --- | --- | --- |
| 256 F56 | 2.9435 / 5.0655 | 2.9689 / 5.0783 | 3.0196 / 5.1038 |
| 256 R5U | 5.2775 / 6.3222 | 5.2778 / 6.3222 | 5.2783 / 6.3222 |
| 512 F56 | 3.2415 / 5.4766 | 3.2947 / 5.4995 | 3.4010 / 5.5452 |
| 512 R5U | 5.5161 / 6.5780 | 5.5167 / 6.5780 | 5.5180 / 6.5780 |

**即使把新增的小角度交叉损耗整体放大到 2 倍，F56 仍显著优于 R5U**（512：
平均 3.401 vs 5.517，最大 5.545 vs 6.578）—— 结论对该近似的不确定性稳健。

### 7.2 间距惩罚的影响（256）

| `spacing_penalty_db` | 平均 | 最大 | 间距违规 |
| --- | --- | --- | --- |
| 0（默认） | 3.4981 | 5.9980 | 576 |

## 8. 限制与失败案例

1. **零水平偏移不可用自由弯角**（几何上无解，见 3.1）：本阶段数据里跨侧连接的
   `dx ≥ 1.475 mm，未出现该情形；测试单独覆盖并把回退行为固定下来（保留 U 型）。
2. **F5 的最差链路几乎没改善（512：−0.132 dB）**，且其最大损耗（6.446）差于
   D0/D56（5.621）—— 只放开路径结构而不放大半径，会让被穿越的路线变差。
   F56 是唯一在平均与最大两头都明显占优的方案。
3. **间距违规随自由弯角上升**（512：711→1231）。如果制造上有真实的最小间距要求，
   自由弯角的收益需要重新评估（可用 7.2 的惩罚项折衷）。
4. 自由弯角路线**不占用水平轨道**（`noCross` 的轨道启发式对它不适用），改为完全依赖
   几何评价（交叉/接触/重合/间距）来防止冲突；重合被硬拒绝，所以不会产生重叠版图，
   但它与 U 型路线之间的"轨道语义"不同，这一点是模型选择，不是原版行为。
5. 半径候选仍只有 R5/R6；中间直线的方向限制在候选网格的 7 个角度上。
6. 交叉损耗表仍是论文图 3-12 的数字化近似；角度按原版 `int()` 截断查询。

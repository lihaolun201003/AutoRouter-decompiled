# 256/512 二维布线：间距、损耗与端口排布

本页只讨论 **256 和 512 波导的二维布线**。前代论文给出的数值、已验证的 512 坐标快照，以及本仓库实现的 512 实验分别标明；不能把 512 快照当作独立 256 布局，也不把后续 1024 三维实验算作二维成果。坐标单位为 mm。

## 1. 波导间距与弯曲半径

| 规模 | 波导宽度 | 标称边缘间隔 | 中心节距 | 弯曲半径的现有证据 |
| --- | ---: | ---: | ---: | --- |
| 256 | 0.05 mm（50 μm） | 0.25 mm（250 μm） | 0.30 mm（300 μm） | 尚未确认独立 256 实验的半径和完整配置 |
| 512 | 0.05 mm（50 μm） | 0.125 mm（125 μm） | 0.175 mm（175 μm） | 前代论文的实验值和当前 512 解析几何均采用 5 mm；旧 EXE 的默认值未确认 |

因此，**512 实验设定**的标称边缘间隔 : 弯曲半径为 `0.125 : 5 = 1 : 40`。256 的间隔数值已见前代论文，但半径未确认，不能给出可靠的“256 间隔:半径”比值。以上间隔是布线输入/轨道节距规则，不证明所有曲线之间的实际边缘距离都满足它。

当前 [`router_2d.py`](../../src/router_2d.py) 的 512 轨道策略使用 `pitch = width + spacing`，轨道中心从 `radius + width/2` 到 `board_height - radius - width/2`。在 150 mm 板高、0.05 mm 宽、0.125 mm 间隔、5 mm 半径下，生成 **800** 个候选轨道。现有 512 快照得到 454 条普通路线轨道分配结果；58 条特殊 Z 另有解析几何，不能把“有解析几何”说成“获得普通轨道”。来源见 [512 轨道分配报告](../reports/step_8_legacy_512_track_assignment_v01.md)与 [512 几何验证](../reports/step_8_5_legacy_512_exact_validation_v01.md)。

## 2. 传输损耗如何计项

当前二维估算在**每条波导**上分别计算传播与弯曲，并以 dB 相加：

```text
已知非交叉损耗 = 传播系数 × 几何总长度 + Σ(各弯曲损耗)
候选完整链路预算 = 输入耦合 + 传播 + 弯曲 + 同层交叉 + 输出耦合
```

[`loss.py`](../../src/loss.py) 沿用前代论文中采用/报告的 **0.05 dB/cm** 传播系数和半径对应的 90° 弯曲损耗表。5 mm 半径对应 **2.39 dB/90°**；代码把该值按实际弯角线性缩放。这些是历史参数与估算假设，并非本项目材料的实测标定。512 条路线已有传播与弯曲的逐路线计算：[损耗报告](../reports/step_8_5_loss_and_angle_v01.md)。

交叉角可以计算，但 `crossing_loss(angle_deg)` 仍未实现；输入/输出耦合和连接器数据也不足。因此，**512 有部分损耗估算，没有可信的完整链路损耗**。256 目前只有输入和部分论文参数得到核验，**没有独立 256 布局上的逐路线损耗分析**。不能把不同波导的 dB 值求和称为单条端到端链路损耗。

## 3. 端口位置如何排布

### 512：有经过验证的坐标快照

512 连接表含 **64 个 PMT，每个 16 个端点，共 1024 个端点**。快照的上下两侧各 32 个 PMT，`y = 0 / 150`。令 `c = 0..31` 为该侧从左到右的 PMT 列号，`j = 0..15` 为组内按 x 升序的几何序位：

```text
下边： (x, y) = (2 + 4.5c + 0.175j,   0) mm
上边： (x, y) = (4 + 4.5c + 0.175j, 150) mm
```

同侧 PMT 起点间距 4.5 mm，上下两侧起点横向错开 2 mm；下边端点 x 范围 2～144.125 mm，上边为 4～146.125 mm。`j` 是从快照坐标推得的顺序，不等于原始端口槽位 ID；快照里的 `index1/index2` 也不是端口槽位。原连接方向须按行号与快照关联，不能把一整侧 PMT 都假定为 source 或 destination。见 [布局审计](../reports/step_8_legacy_layout_audit.md)和 [端点快照验证](../reports/step_8_legacy_512_snapshot.md)。

前代论文描述了按目标 PMT 相对位置（左、对侧、右）分组，再按目标 PMT 编号排序并分配端口位置的思路。**快照坐标已确认，原布局生成程序和完整槽位分配规则尚未恢复。** PMT 机械中心、封装边界和端口法向也未确认。

### 256：连接已核验，独立坐标布局未重建

256 输入有 **256 条连接、32 个 PMT，每 PMT 16 个端点**。[原始 256 工作簿](source_data/fiberBoard256.xlsx) 只有 `Port1`、`Port2` 两列和 256 行连线，没有 x/y 坐标或端口槽位列。论文给出 50 μm 波导宽和 250 μm 间隔；但目前没有与独立 256 实验对应、经过验证的 PMT 坐标/端口槽位快照。原始目录中的演示视频可以辅助视觉核对，不能替代数值坐标。不能从 512 的公式截取一半来声称已得到 256 排布。见 [输入验证](../reports/step_8_legacy_input_validation.md)和 [布局审计](../reports/step_8_legacy_layout_audit.md)。

## 4. 当前结论

- **512：** 宽度、间隔、半径和快照端口坐标已有；解析二维路线及部分损耗估算已有。真实最小曲线间距、交叉损耗、完整链路损耗与制造约束仍缺。
- **256：** 连接表及论文中的宽度/间隔已有；独立端口坐标、半径配置、路线和逐路线损耗尚未完成核验。

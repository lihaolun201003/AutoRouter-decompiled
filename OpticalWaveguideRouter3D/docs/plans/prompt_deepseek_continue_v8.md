五、必做任务P1：实现并验收v8几何支持链
使用冻结平面路径弧长s定义(x(s),y(s),z(s))，允许合法窗口切分圆弧、跨相邻primitive。新窗口保留原XY路径，不能接直线chord替代圆弧；内部切分保留完整升/降窗的共同相位，不能每片重新开始余弦升降。
逻辑上仍只有一次升和一次降，物理片段可以多于两个；同步适配elevated检测、层状态、结构判定与当前长度。
先支持新原语及候选，再同步point_at/tangent、长度/收敛、曲率、XY定位、RouteView、保守包围与弦误差界、primitive两两近距、自近距、序列化重载、绘图、缓存指纹和稳定排名字段。不要让新旧窗口编码在排序时类型不兼容。

几何要求：
- 三维曲率为||r'×r''||/||r'||^3，必须验证整个窗口和接续两侧，不用离散采样最小半径冒充可靠下界。
- 若s为平面弧长，速度为sqrt(1+z_s^2)，长度积分为其积分；XY曲率影响三维曲率，不能误把曲率硬塞进该速度公式。
- 可推导并验证 kappa3D = sqrt(kappaXY^2*(1+z_s^2)+z_ss^2)/(1+z_s^2)^(3/2)，明确适用参数和片段边界。
- 原弧半径贴近要求时新增升降可能不可行，保守拒绝；不得降低半径要求或改XY。
- 保守距离必须有可复核界；不支持、未收敛和阈值不确定都不能记CLEAR。
- 原直线候选退化情况、旧序列化与旧策略默认行为兼容。旧路径采样检查仅作交叉核对，新原语XY保持应有构造依据与验证。

针对性测试要覆盖：纯直线退化、线—弧/弧—线跨窗、内部相位与方向连续、升降不重叠、目标覆盖、曲率超限/可行边界、长度不收敛、旧/新和新/新primitive距离、自近距、逻辑结构、round-trip、缓存失效与增量集合一致。

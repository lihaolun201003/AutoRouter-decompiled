## 2 问题清单（按可操作性排序）

### 2.1 ASCII 标识符在单元格内被拆断（唯一成规模的问题，共 121 处，涉及 P2–P7、P9–P11）

机器清点（同块相邻行 + 左边界对齐 + 首尾均为 [A-Za-z0-9_]）：P2 3、P3 6、P4 4、P5 23、P6 15、P7 18、P9 7、P10 23、P11 22 = **121 处**。典型：

- §4：V8_G0_NEUTRALITY_R2880 → 「V8_G0_NEUTRAL」/「ITY_R2880」（同型 3 行）
- §3.1：V8_G1_RC2880 → 「V8_G1_RC288」/「0」（P3）
- §6/§7.1：BASE_E2 → 「BASE_」/「E2」；A_FAMILY → 「A_FAM」/「ILY」
- 聚合表：BASE_E2_T2000 → 「BASE_E2_T20」/「00」；A_FAMILY_T2000 → 「A_FAMILY_T2」/「000」
- §9：V8_G0_NEUTRALITY_N1440 → 「…_N144」/「0」；P3_A_FAMILY_T2000_NC2880 → 「…_NC2」/「880」

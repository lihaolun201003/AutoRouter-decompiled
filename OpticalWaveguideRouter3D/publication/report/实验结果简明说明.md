# 实验结果简明说明

这份说明只回答三个问题：做了什么实验、结果怎么样、得出了什么结论。数字来自已保存的实验输出，本次没有重新运行实验。

## R5、R6 是什么

R 是波导转弯圆弧的半径，单位是 mm。**R5 = 5 mm，R6 = 6 mm**。

实验清单还有带前导零的 **R05、R06**：它们是实验编号，分别对应“512 通道、半径 2 mm 扫描”和“512 通道、半径 3 mm 扫描”。查看时要区分清单编号与图中的半径参数。

半径越大，转弯越缓，占用的转弯空间也更大。本项目损耗模型中，一次 90° 转弯的损耗约为：R5 2.38 dB，R6 1.90 dB。因此我们比较 5 mm 和 6 mm，是为了测试扩大半径能否降低损耗、是否还能把全部连接布通。

F56 表示“自由弯角路径 + 从 5/6 mm 半径中选择”，不是 56 mm 半径。自由弯角的意思是：跨上下两侧的连接允许用斜线和较小转弯角度，不强制两次 90° 转弯。

## 做了哪些实验，结果与结论是什么

### 1. 原程序复现：能否得到相同路线和接近的损耗

做法：恢复原程序的二维排布与圆弧构造，在 150 × 150 mm 区域布置 256、512 条连接，并计算直线、弯曲、交叉三部分损耗。

| 实验 | 复现平均损耗 | 复现最大损耗 | 原报告平均 / 最大 |
| --- | ---: | ---: | ---: |
| 256 通道，R5 | 5.2788 dB | 6.3330 dB | 5.3 / 6.4 dB |
| 512 通道，R5 | 5.5147 dB | 6.5761 dB | 5.5 / 6.6 dB |
| 512 通道，R4 | 9.8096 dB | 10.9815 dB | 9.8 / 11.0 dB |

结论：主要损耗数值接近原报告；512 条路线的轨道与弯曲几何也与所恢复的原程序逐条一致。损耗中交叉项使用原报告图线提取的近似表，原始交叉损耗表没有取得。

来源：[复现汇总表](<C:/Users/lihao/Desktop/Graduation Project/OpticalWaveguideRouter3D/publication/tables/t32_reproduction_compare_data.csv>)、[原程序几何一致性记录](<C:/Users/lihao/Desktop/Graduation Project/OpticalWaveguideRouter2D/docs/exact_legacy_fidelity_report.md>)。

### 2. 半径实验：转弯半径对损耗有多大影响

做法：512 通道分别采用 2、3、4、5 mm 半径重新布线并计算损耗。

| 半径 | 平均损耗 | 最大损耗 |
| --- | ---: | ---: |
| 2 mm | 16.5873 dB | 17.7056 dB |
| 3 mm | 14.2260 dB | 15.4284 dB |
| 4 mm | 9.8096 dB | 10.9815 dB |
| 5 mm | 5.5147 dB | 6.5761 dB |

结论：在这组实验和模型中，扩大半径明显降低损耗。512 通道 R5 的损耗中，弯曲占约 82.7%，直线占 11.5%，交叉占 5.8%，因此减少弯曲损耗是主要改进方向。

来源：[半径扫描数据](<C:/Users/lihao/Desktop/Graduation Project/OpticalWaveguideRouter3D/publication/tables/t33_radius_sweep_512_data.csv>)、[各半径独立布线脚本](<C:/Users/lihao/Desktop/Graduation Project/OpticalWaveguideRouter2D/tools/radius_sweep.py>)。

### 3. 轨道与半径选择：只优化候选位置是否有效

做法：比较原版 R5、统一 R6、固定 R5 的候选轨道优化，以及允许选择 R5/R6 的方案。

结果：512 通道只优化 R5 轨道，平均损耗从 5.5162 降到 5.5146 dB，改善很小；统一 R6 有 2 条未布通；自适应选择 R5/R6 后全部布通，平均损耗为 4.5593 dB。

结论：这批数据中，收益主要来自扩大半径；单纯增加轨道搜索的收益很小。统一放大半径会遇到空间限制，需要允许局部使用较小半径。

来源：[候选优化对照表](<C:/Users/lihao/Desktop/Graduation Project/OpticalWaveguideRouter3D/publication/tables/t51_step12_main_data.csv>)。

### 4. 路径结构实验：能否减少总转弯角度

做法：保持每条连接的起终点不变，把跨上下两侧的连接改成“圆弧 + 斜线 + 圆弧”，并从 5/6 mm 半径中选择。下表使用补修后的结果。

| 规模 | 原版平均 → 自由弯角平均 | 原版最大 → 自由弯角最大 |
| --- | ---: | ---: |
| 256 | 5.2786 → 2.9703 dB | 6.3333 → 5.0783 dB |
| 512 | 5.5162 → 3.2947 dB | 6.5773 → 5.4995 dB |

结论：减少转弯角度比单纯搜索轨道更有效，平均和最大损耗都有改善。代价是交叉损耗增加，小角度交叉和间距不足也更多。例如 512 通道平均交叉损耗从 0.3219 增到 0.5650 dB，间距违规路线对从 692 增到 1231。因此低损耗结果仍需进一步处理几何风险。

来源：[补修后的主结果](<C:/Users/lihao/Desktop/Graduation Project/OpticalWaveguideRouter3D/publication/tables/t61_step13_main_data.csv>)、[后续统一统计记录](<C:/Users/lihao/Desktop/Graduation Project/OpticalWaveguideRouter3D/docs/reports/step_14_opt2d_frozen_robust_optimization.md>)。上表基准采用解析几何统计，与第 1 项原版整数角度统计略有差别，不能混用精确小数。

### 5. 风险与保护实验：改善交叉时能否保护已有路线

做法：冻结端点和每路半径，分别惩罚间距不足、小角度交叉，并要求最差路线与固定保护路线不变差。另把小于 20° 的交叉损耗乘以 5，作为压力情景。

结果：单独加入间距或小角度惩罚能减少相应风险，但这些配置未通过全部保护条件。保护性局部优化在 512 通道接受 6 个候选：标称最大损耗 5.4995 → 5.4654 dB，压力情景最大 5.7264 → 5.6340 dB，保护路线均未恶化；256 通道没有候选满足严格条件，结果保持原样。

结论：进一步优化的收益较小，而且不同规模的表现不同。降低某一类交叉或间距违规，并不自动保证整体损耗和每条关键路线都改善。把小角交叉损耗乘以 10 时，512 优化方案的情景最大损耗反而从 8.4333 升到 8.4996 dB，不能宣称所有风险情景都改善。乘以 5 或 10 是人为压力情景，不代表实测误差。

来源：[512 配置结果](<C:/Users/lihao/Desktop/Graduation Project/OpticalWaveguideRouter3D/outputs/opt2d_step14/512/comparison.csv>)、[512 验收结果](<C:/Users/lihao/Desktop/Graduation Project/OpticalWaveguideRouter3D/outputs/opt2d_step14/512/acceptance.csv>)、[256 验收结果](<C:/Users/lihao/Desktop/Graduation Project/OpticalWaveguideRouter3D/outputs/opt2d_step14/256/acceptance.csv>)、[512 压力情景数据](<C:/Users/lihao/Desktop/Graduation Project/OpticalWaveguideRouter3D/outputs/opt2d_step14/512/sensitivity.csv>)。

### 6. 三维抬层实验：把部分波导抬高能否减少碰撞

做法：先在 512 条连接上比较两层与三层；再把固定输入确定性扩展到 1024 条连接，在 300 × 200 mm 区域使用 z = 0/1/2 mm 三层，尝试局部抬高路线。

结果：512 通道同样尝试 50 次，两层终态近距路线对为 46624，三层为 45400，三层增加的长度和运行时间更多。1024 通道成功抬升 175 条路线，近距路线对从 204291 降到 138113，减少 32.39%；运行约 19.5 分钟，累计额外长度约 87.41 mm，另有 4 对未决。

结论：局部抬层能减少几何碰撞，但仍剩大量近距路线对，尚未获得无碰撞版图。这里验证的是几何改善，没有计算三维光学损耗，也没有制作器件实测。

## 汇报时可以直接这样说

我们首先复现了原来的二维自动布线，得到了 256 和 512 条波导布局，损耗数值与原报告接近。随后比较转弯半径、候选轨道和路径形状，发现主要损耗来自弯曲：扩大半径、减少总转弯角度能明显降低计算损耗，但会增加部分交叉和间距问题。最后进行了三维抬层实验，1024 条连接的近距路线对减少了约三分之一，但还没有实现无碰撞布线。

以上损耗均为模型计算值；平均、最大值描述的是一次布局内各条路线的结果。

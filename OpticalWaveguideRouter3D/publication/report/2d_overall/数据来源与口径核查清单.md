# 数据来源与口径核查清单

配套文件：《二维光波导自动布线总体实验报告》（同目录 .md / .docx / .pdf）。

核查日期：2026-10-05　　核查范围：二维（256 / 512 通道）全部已有实验产物

## 0. 核查方法与证据优先级

1. **只读核查。** 本次没有修改 `OpticalWaveguideRouter2D`、`OpticalWaveguideRouter3D` 下的任何既有文件，没有重新运行路由或优化，没有改动任何输入、参数或历史记录。新增内容只写在本目录（`2d_overall/`）内。
2. **证据优先级：原始产物 > 已完成的补修复验 > 旧报告正文。** 凡报告正文与 CSV/JSON/XLSX 冲突处，一律以产物为准并在本清单记录。
3. **口径必须先定后比。** 不同端点来源、不同半径、不同评价器、不同损耗口径的数据不放进同一张公平比较表；必要时并列但显式标注"不可直接比较"。
4. **复核方式：** 逐条读取 `OpticalWaveguideRouter3D/outputs/opt2d*`、`OpticalWaveguideRouter2D/results/`、`publication/tables/` 的原始文件；对轨道数、P95、事件计数等可独立复算的量做了独立重算（见第 4 节）。

## 2. 统计口径定义（引用数字时必须带口径）

| 口径名 | 定义 | 出处 |
| --- | --- | --- |
| 解析物理口径 | 直—直/直—弧/弧—弧精确求交、真实切线角、逐路损耗 | `OpticalWaveguideRouter3D/src/opt2d/intersections.py`、`evaluator.py` |
| 原版 `calc_index` 口径 | 弦近似求交 + 整数度查表；仅作参照 | `OpticalWaveguideRouter2D/waveguide_calculator.py` |
| 解析段级事件 | 段对层面的相交事件，可重复计数 | `spacing_report` |
| 位置聚类事件 | 同一路线对同一位置的重复记录按坐标聚类后的事件 | `physical_intersections` |
| 纯路线对 | 再按整条路线合并，同一对路线只算一次 | 同上 |
| P95 | 升序后第 `ceil(0.95N)` 个值（**最近秩**，非线性插值） | `src/opt2d/evaluator.py` `_percentile` |
| 小角度交叉计数 | **全网唯一物理交叉事件数**（非逐路累计） | `src/opt2d/step13.py` `angle_histogram` |
| 间距违规 | **路线对**计数（非段对） | `src/opt2d/planner.py` |
| 物理接触 | 位置聚类后按整条路线合并的接触事件；两规模均为 0 | `evaluator.py` |
| 重合 | 两条路线共用一段轨迹，几何违规，硬拒绝 | `intersections.py` |
| 压力情景 ×k | 把 <20° 交叉事件损耗乘以 k 后**固定几何复算**，不重新布线 | `step14.py` |
| 半径冻结 | 全部配置通过 `radius_overrides` 传入同一份逐路半径表 | `planner.py` |
| 运行时间 | 每个配置仅一次记录；`comparison.runtime_s` 与 `optimize_record.runtime_s` 口径不同 | 见 3.5 |

### 3.6 出版表 t63 的表题（本次新发现）

`publication/tables/t63_step13_constrained.tex` 的表题写作"受约束复算（几何不变，仅改评分）"，**不成立**：Step 13 受约束实验在配置间**改变了个别路线的半径** —— 256 的 spacing / small / both 各有 **5 / 11 / 6** 条由 R6 变为 R5，512 为 **10 / 4 / 11** 条；冻结的只是端点与几何族。因此该实验**不能作为纯约束对照**，纯约束对照由 Step 14 的冻结半径实验承担。出版文档自身亦自相矛盾（2.4 节表注与正文警告不一致）。

## 重新生成

```powershell
# 在 OpticalWaveguideRouter3D 根目录执行
.venv\Scripts\python.exe scripts\publication\make_report.py
```

该入口依次运行 `build_report_docx.py`（复制模板生成 docx）与 `export_report_pdf.py`
（Word 更新域 → 导出 PDF → 另存 .doc → 渲染检查图）。
要求本机安装 Microsoft Word；不修改任何原始实验数据与模板原文件。

重新生成前如需更新图/表本身，先运行 `make_publication.py`（见上级目录 README）。

## 模板遵循情况

- 基于项目自带模板《李昊伦_本科毕业论文_格式模板.docx》**复制**生成（原文件未被修改）；
- 使用模板原生样式：章/节标题（自动编号"第 X 章 / X.Y"）、正文（宋体 + Times New Roman、固定 20pt）、
  图题（图下）、表题（表上）、参考文献（自动 [n] 方括号编号）、页眉页脚；
- 页面：A4、四边 30 mm；正文页眉"电子科技大学学士学位论文"，页码居中；
- 表格：Word 原生三线表（0.5pt 顶线/表头线/底线），长表重复表头，列宽按内容自动分配；
- 公式：Word 原生公式（OMML），居中 + 右编号（2-1、2-2）；
- 图表编号：图 X-Y / 表 X-Y（手写编号 + 书签 + REF 交叉引用域，Word 中可 F9 更新）；
- 目录：自动 TOC 域（已由脚本更新并固化在 docx/PDF 中）。

## 页码说明

- 封面：不显示页眉页码（模板"首页不同"）；
- 前置部分（摘要、Abstract、目录、符号表）：小写罗马页码 ii–vi——封面计入第 i 页但不显示，
  摘要从 ii 起（排版权衡：模板本身不含封面；如需摘要显示为 i，请在 Word 中把前置节页码格式
  起始值改为 0 或手动调整）；
- 正文及后置（参考文献、致谢、附录）：阿拉伯页码从 1 连续编号（1–47）；
- 无任何空白页（已逐页核验）。

## 报告内容口径（与实验记录一致）

- 全部损耗为论文模型框架下的**计算值**，不是器件实测；
- 路线平均/P95 是**单次布线的逐路统计**，不是重复实验统计；
- 原版统计与解析物理统计分开说明；raw 段级接触与物理接触分开命名；
- 历史非法几何（旧版 256 F56 的 #7/#31 重合 152.007 mm）仅作历史记录；
- 纯约束比较使用 Step 14 冻结半径数据；保护对象使用固定的 11 条 ID 集合；
- 未布通、未通过验收、诊断结果均明确标注；×5/×10 为压力情景；
- 三维结果只支持几何指标，不声称光学损耗改善；
- 正文关键数字由 `report_content.py` 从实验产物（publication/tables/*_data.csv 等）读取注入。

## 生成脚本

| 脚本 | 职责 |
| --- | --- |
| `make_report.py` | 一键入口（构建 + 导出） |
| `build_report_docx.py` | 基于模板生成 docx（封面、前置、8 章正文、后置与附录、三线表、OMML 公式、交叉引用域） |
| `export_report_pdf.py` | Word COM：更新域与目录、导出 PDF、另存 .doc、渲染逐页 PNG |
| `report_content.py` | 关键数字注入（从实验产物读取）、图/表元数据、参考文献 |
| `report_body.py` | 正文文本（8 章） |

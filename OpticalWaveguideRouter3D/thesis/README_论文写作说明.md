# 论文模板使用说明

本目录只提供格式与占位结构，没有论文正文、摘要、结论、致谢或真实参考文献。

## 官方依据与装订

唯一依据：用户提供的《本科毕业设计（论文）管理办法》附件二《学士学位论文撰写格式规范》。未采用网上模板。

正式装订顺序：封面 → 任务书 → 开题报告表 → 进度计划表 → 初期检查表 → 中期检查表 → 答辩提问记录表 → 成绩考核表 → 学术诚信声明 → 中文摘要 → 英文摘要 → 目录 → 主要符号表（可选）→ 绪论 → 论文主体 → 结论 → 致谢 → 参考文献 → 附录 → 外文资料原文 → 外文资料译文 → 封底。

模板从中文摘要开始。正式封面和学校统一表格另行取得，不在模板中仿造。外文资料原文和译文已保留占位页；封底由装订环节提供。

## 开始写作

1. 先另存为写作副本，保留格式模板。将【待填写】替换为内容，不粘贴来源文档的格式。
2. 正文使用 `Thesis Body`。中文宋体、英文数字 Times New Roman、12 pt、固定 20 pt、首行 24 pt（两个汉字宽），通过段落属性缩进。
3. 章使用 `Thesis Chapter`；节依次使用 `Thesis Heading 1/2/3`。编号由关联多级列表产生，不要在标题文字内再键入序号。
4. 每章另起页。第一章以奇数页起始，第二章以后使用下一页分节，不强制奇数页。
5. 两标题相邻且中间无正文时，选中第二个标题，将“段落→段前”改为 0 pt。不要全局修改标题样式。当前章后紧接的首节已这样处理。
6. 目录右键“更新域→更新整个目录”；也可 Ctrl+A、F9。目录只含正文及致谢、参考文献、附录等后置标题，前置部分不列入。
7. 更改章名后更新正文页眉域。奇数页取当前章标题，偶数页固定为学校学位论文名称；后置部分使用其标题。

## 摘要与前置分页

中文摘要未来填写 300～500 字，关键词 3～5 个；英文摘要内容对应中文摘要。当前均仅为占位。主要符号表的“含义”将来同时写中英文解释，不必为少量符号强行保留该页。

前置部分分别双面印制，各部分若有奇数页，则背面留白且不印页眉页码。模板用奇数页分节留白；最终内容长度变化后，必须检查罗马数字是否只对有内容的前置页连续编号。必要时在“设置页码格式”中调整下一部分起始编号。不得用多次回车插空白页。第一章阿拉伯页码重新从 1 开始。

当前预览中中文摘要为 i、英文摘要为 ii、目录为 iii～iv、符号表为 v。Word 奇数页分节会调整内部页码奇偶性，英文摘要页脚因此使用嵌套域 `{ = { PAGE \\* Arabic } - 1 \\* roman }` 显示 ii。内容长度变化后，须同时检查各节页码起始值及该偏移量；这部分不保证随任意增删页完全自动保持连续。空白背页不显示页眉页码。此项为 `MANUAL_CHECK_REQUIRED`。

## 图表公式与引用

图位居中，`Thesis Figure` 与下一段保持同页；图题用 `Thesis Figure Caption`，表题用 `Thesis Table Caption`。复制示例时包含完整域，用 Alt+F9 查看域代码，F9 更新。题注章号使用 `SEQ ThesisChapter \\c`，图、表、公式各自使用带 `\\s 1` 的 SEQ 域按章重新编号。不要直接改用内置“包含章节号”方案：本模板章标题是中文数字，该方案可能得到“一-1”而非“1-1”。

每个章标题末尾保留一个隐藏输出的 `SEQ ThesisChapter \\h` 章计数域。新增章时复制完整章标题段落并修改标题；仅套用章样式不会自动插入该域。用 Alt+F9 检查每章恰有一个计数域；若缺失，以 Ctrl+F9 插入域括号并填写代码，不手打花括号。增删或移动章后更新全文域，核查章号与题注章号一致。

图名与图序之间一个半角空格；官方例子为“图1-1”，不是“图 1-1”。表题在表上方、图题在图下方。表线为 0.5 pt 单线，表格行禁止跨页。较大表格及长图题须人工核对同页与续排；多行图题按官方要求左右缩进两字并使回行与图名对齐。

公式样式已设置居中制表位和右对齐编号制表位，正文位置插入原生 Word 公式；不得转换成伪公式图片。正式数学符号需逐项核查斜体/正体及数学字体；本次只有公式占位。

参考文献示例不是可引用文献。正式条目按引用顺序自动编号，中文宋体五号、英文数字 Times New Roman、固定 20 pt，一条内不分页。普通正文引用用 12 pt 字号上标 [1]；“由文献[1]可知”这种句子成分不设上标。具体著录格式以附件二“二、7”给出的 J/C/M/D/N/R/P/S 和电子文献规则为准。

## 交稿前人工检查

- 更新所有域和整个目录，核对目录页码、章序以及增删图表后的编号。
- 检查各前置部分奇数末页背面的空白、无页眉页码及罗马编号连续性；第一章实体页应是正面。
- 检查长标题是否换行、相邻标题段前距、标题后至少有两行正文，以及图表和题注同页。
- 补足学校统一表格，按官方顺序装订；成绩考核表之外的前置表格单面印制，正文双面。
- 模板含 7 个正文章，长章名为满足一行要求已缩短；章节名称可在不改变格式的前提下调整。

# V3-Huang comparison/ artifacts

Generated by `four_side_1024.v3.compare` (metrics/plots owner). Every number in the JSON/CSV files is recomputed from the saved world-mm primitives of the runs named in `all_metrics.json`; nothing is estimated.

## Data files

* `all_metrics.csv` / `all_metrics.json` -- one row per plane run and per combined layout (`role` column); full Phase-6 metrics plus declared-vs-recomputed reconciliation and failure taxonomy.
* `strict_audit_summary_metrics.json` -- metrics-side merge of the per-plane authoritative `audit_strict.json` files (the validator owns `strict_audit_summary.json`, which is never overwritten here).
* `key_numbers.json` -- headline numbers per run, contract, audit and reconciliation summaries (machine-readable for the report).
* `connector_matrix_64x64.json` -- directed + symmetric matrices computed directly from the frozen CSV.

## Definitions (shape/geometry)

* **Path shapes are classified from saved primitives only** -- never from the CSV relation/pair label. Classes: straight / short_S / L / U / multi_bend_refold / other.
* **U** = net-180-degree same-side U/hairpin path: `wide_U` (two quarter arcs with straight track), `hairpin` (two consecutive quarter arcs), `hairpin_short_S` (one hairpin + one historical short-S lateral shift, the SAME_HAIRPIN_A/B families).
* **other** = two-quarter step transfer (two quarter arcs with opposite sweeps, net turn 0 deg -- the FSLW opposite-side `U` transfer family); the required taxonomy has no step class, so it is kept as `other` and not counted as U.
* U depth = inward distance from the shared board edge to the deepest point/track; track_count = straight segments parallel to that edge with length >= 0.5 mm (0 for pure hairpin-family paths).
* U nesting = inner U's along-edge interval contained in the outer U's interval with a deeper track; adjacent-U spacing = exact minimum centreline distance between consecutive U tracks with overlapping intervals (violation threshold = clearance - 1e-7 = 0.0799999 mm).
* refold = three or more quarter arcs, two or more hairpins, or a short-S combined with additional quarter arcs; refold-region congestion = refold-only centreline length per 5x5 mm cell.

## Honesty / loss policy

* Same-plane crossings and strict-policy violation counters come from the authoritative `planes/<A>/<z>/audit_strict.json` (stale files ignored); the recomputed strict kernel agrees with the validator on the smoke runs.
* Only propagation loss is computed (0.05 dB/cm). Bend loss and crossing loss are `unknown_uncalibrated`; total optical loss is reported as `not_computable_missing_calibration`, and the legacy polymer estimate is never used as glass truth.
* z1 (CSV row 1) and z2 (CSV row 2) are independent 2D planes at model heights 0.0/0.5; cross-plane XY projections are informational only and never violations (SPEC §2).
* `key_numbers.json` records the declared-vs-recomputed reconciliation: routed counts, lengths, bend counts and propagation loss are compared against the router's own `routes.json` values and reported even if non-zero.

## 8. Honest limitations

- All coordinates in this audit are simulation under the two-height interface assumption (z1 = 0.0 mm, z2 = 0.5 mm are model values); glass thickness and connector mounting direction are not confirmed.
- No z transition (via / taper / fanout) is implemented; the two planes are independent 2D routing problems and cross-plane XY projections are NOT same-layer conflicts.
- 9 mm connector pitch mechanical interference is unresolved: the provisional MPO housing envelope 12.59 mm overlaps neighbouring housings by 3.59 mm (the 3.75 mm fiber span itself fits); this is inherited from the FSLW round.
- The V3 topology is a synthetic 1024-channel expansion of the user-provided 512 fiberBoard (doubling + 96 NS/EW direction exchanges + Euler row/column fibre assignment); it is a topology baseline, not a measured or hardware validated demand (see the workbook generation-notes sheet).
- Same-side connections (448 = 43.75%) require hairpin/U (refold) routing; the previous fslw loader rejects same-side connections and assumes row1=opposite / row2=adjacent, so V3 needs the new loader/validator.
- The relation is authoritative from the CSV relation column; the row only selects the dual-height plane. Row 1 contains 222 same + 196 opposite + 94 adjacent; row 2 contains 226 + 188 + 98.
- Excel Sheet1 Port1/Port2 uses 1-based connector indices 1..64 following the port-map sheet (N01=1 ... W16=64); all 1024 rows match the CSV in order.
- Cross-plane XY projections are not same-layer conflicts; conflict checking is per plane only.
- This is a *topology/interface audit only*: no routing (D56 R=40 mm) was run, so no routed count, spacing or crossing result is claimed here.
- The V3 topology is synthetic (generated from the 512 fiberBoard): it is a baseline for algorithm experiments, not a measured demand.

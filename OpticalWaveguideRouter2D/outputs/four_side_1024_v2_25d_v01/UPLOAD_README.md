# 公开仓库说明：五层 2.5D 局部抬升双方案（2026-10-20）

本目录对应 `docs/reports/four_side_1024_v2_25d_v01.md`（仓库根 docs）。

- **模型**：保留真实 2x16 双高度接口（z1 接口 z=0、z2 接口 z=0.5 mm）与两组已验收二维布局；
  新增五个布线高度 z = [0, 0.125, 0.25, 0.375, 0.5] mm（3 层对照 [0, 0.25, 0.5]）。
  每条抬升路线 = 接口层平坦段 -> 双 R40 弧 S 曲线上升 -> 中间层平坦传播 -> 双 R40 弧 S 曲线下降
  -> 接口层平坦段；S 曲线水平投影为轴对齐直线段（不改变 A/B 的二维 XY 模型），起终点切向水平，
  完整三维路径最小曲率半径恰为 40 mm。所有路线之间做真三维净空检查（>=0.08 mm），
  不忽略不同层之间的冲突。
- **结果**（四个 run 均通过独立三维验收 PASS、8 类违规计数全 0）：

| run | 基线 | 布通 | 新增 | 抬升/升降 | 实际 3D 交叉 | 2D 平铺交叉 | 消除交叉 |
|---|---:|---:|---:|---:|---:|---:|---:|
| A 3 层 | 752 | 788 | +36 | 36 / 72 | 87,240 | 93,753 | 6,513 |
| A 5 层 | 752 | **820** | +68 | 68 / 136 | 87,279 | 104,076 | 16,797 |
| B 3 层 | 262 | 342 | +80 | 80 / 160 | 10,822 | 21,575 | 10,753 |
| B 5 层 | 262 | **383** | +121 | 121 / 242 | 11,138 | 34,091 | 22,953 |

  全局最小三维间距 A 0.080390 mm（紧，来自已验收二维基线自身的同层最小间距）、
  B 0.092446/0.091117 mm；最小曲率半径 39.9999997 mm。
  剩余失败：无二维候选 A 42 / B 426（抬升无效，单独统计）；有候选但升降净空不足 A 162 / B 215。
- **边界**：本实验只做"单次升降"的 2.5D 局部抬升，不包含 Native 3D 联合寻路；
  层高为仿真假设，不代表工艺已确认；不宣称可制造。

# 结构化分层布线实验（A/B 两组）

基于 `spatial_u_bundle_optimization`（commit `61491c8`，Manual-C4 Spatial U-bundle）
开展的新一轮三维分层优化：不再让算法随机决定不同波导的目标层，而是按连接类型与
空间区域组织布线。

## 目标分层方案（固定）

| 连接类型 | 条数 / 组数 | 目标层 |
|---|---|---|
| 邻边 adjacent | 496 条（124 组） | 保留接口层 L1-z1(0)、L1-z2(0.5)，平铺无升降 |
| 对边 opposite | 272 条（68 组） | 集中 L2（1.0 mm），重优化 XY/升降位置；不可行时允许少量例外并记录 |
| z1 四边中间 U（20–35）+ z2 第一组角部 U（144–159） | 128 条（32 组） | L3（1.5 mm） |
| z2 第二组角部 U（160–175） | 64 条（16 组） | L4（2.0 mm） |
| z2 四边中间 U（176–191） | 64 条（16 组） | L5（2.5 mm） |

A 组保持原 z1/z2 连接分配；B 组把 z1/z2 两张 512 条连接表整体交换到对方的物理接口
排（端点行号/plane 交换、连接关系不变），两组独立保存，不混用结果。

## 方法

1. **全平铺基底**：把全部 1024 条路线的、已经通过 2D 验收的 Manual-C4 二维走线
   平铺在各自接口层（z=0 / 0.5），得到天然合法的三维初始布局（所有 U/对边/邻边
   此时都无升降）。
2. **对边升 L2**：55/66 组… 通过逐组可行性扫描 + 例外优先/困难组优先装配，在
   "全平铺预留"世界里把对边四元组抬到 L2：端口→延长 base 直线→S 上升→L2 直通→
   S 下降→延长 base 直线→端口；C4 四元组原子提交、组内成员互检。
3. **U 线束重构**：端口→延长入口直线→S 上升→目标层 90°圆弧+中间直线+90°圆弧→
   S 下降→延长出口直线→端口；束内按 separation 嵌套（外深内浅）、同层平行不交叉，
   目标层固定；升不起的组保留接口层平铺并记录失败原因。
4. 所有候选都做完整 XYZ 碰撞检查（含跨层升降段），最终用冻结的
   `l3d.validate_payload`（V4 identity）做权威验收。

## 结果

| 指标 | A（原分配） | B（行交换） | 旧 Spatial U-bundle | 前置 V2 动态优化 |
|---|---:|---:|---:|---:|
| 总布通数 | **1024/1024** | **1024/1024** | 1024 | 1024 |
| 邻边保持接口层 | 496 | 496 | — | — |
| 对边集中 L2 | **54/68 组（216 条）** | **66/68 组（264 条）** | — | — |
| 对边例外（保留接口层） | 14 组 / 56 条（5.5%） | 2 组 / 8 条（0.8%） | — | — |
| U 目标分层 | **64/64 组（256 条）** | 16/64 组（64 条） | 64/64（旧方案） | — |
| 全局唯一交叉对 | 19,584 | 26,152 | 12,824 | 23,356 |
| 升降次数 | 944 | 656 | 824 | 440 |
| 三维总长 (mm) | 98,033.77 | 99,554.33 | 98,539.01 | 97,495.76 |
| 最小三维净空 (mm) | **0.0917** | **0.0849** | 0.0832 | 0.0832 |
| 独立 3D 验收 | **exploratory PASS，9 类 counts 全 0** | **exploratory PASS，9 类 counts 全 0** | PASS | PASS |
| 各层波导数 L1-z1/L1-z2/L2/L3/L4/L5 | 512/512/216/128/64/64 | 512/512/264/40/0/24 | 512/512/252/80/68/12 | 512/512/124/36/24/36 |

结论：**A 为最优可行方案**——1024 全布通、规则分层（496+216+256）基本达成、几何
合法（净空 0.0917）。B 交换行后：对边集中 L2 反而更好（66/68 组），但 U 规则分层
严重不可行（仅 16/64），因此 B 只能作为"规则分层不可行性"的对照，不推荐采用。

## 失败瓶颈与原因（均保留合法结果并逐组记录）

### A：对边 14 组无法集中到 L2（保留接口层，`opposite_assignment.json` 记录）

A 的四元组在对边升 L2 时，S 上升/下降段必须从接口层 z=0 穿越 z=0.5 平面，而
Manual-C4 二维底图中同一列/排的 z2 层相邻路线（另一排的平铺路线）恰好与该对边
线路共线/近平行（"影子路线"），在 0.08 mm 净空与"每条最多 1 升 1 降、C4 四元组
同时升降"约束下，无论直线长度/升降窗口/绕行如何调整都存在 transition_vs_flat
冲突，故 14 组按例外保留接口层平铺（56 条，占 1024 的 5.5%），不伪造成功。

### B：U 规则分层 48 组不可行（保留接口层，`u_layer_assignment.json` 记录）

行交换后原 z2 的 U 四元组落到 z1 基排（z=0），而其端口列在 z2 行上被对边连接
占用（两排端口共享同一 XY）；对边连接从 z=0.5 抬升的 base/S 过渡，与该 U 从
z=0 抬升的 S 过渡在接口平面同列，任何 (a, D) 以及在"对边保持平铺/抬升 L2"
两种方案下都无法同时满足 0.08 mm 净空（角部 144–175 共 32 组结构性不可行；
z1_middle/z2_middle 另有 16 组因全平铺基世界过密不可行）。因此 B 的 U 目标层
覆盖仅 16/64，其余 48 组保持接口层平铺并在 `summary.u_failures`、
`u_layer_assignment.json` 逐组记录原因；B 的 1024 条连接与几何仍全部合法
（权威 3D PASS），但"规则分层"目标未达成，故 A 优于 B。

另：A/B 的唯一交叉对高于旧 Spatial-U（19584/26152 vs 12824）是"对边全部集中
L2"的固有代价——NS 与 EW 直通线在 z=1.0 形成大量 90° 交叉；任务目标顺序为
布通/合法 > 规则分层 > 减少异常抬升 > 交叉与总长，故如实报告该 trade-off。

## 复现要点

- 环境：`.venv\Scripts\python.exe`（Python 3.10），`PYTHONPATH=仓库根`。
- 2D 底图：`outputs/manual_c4_new_connectivity/phase2_2d/{z1,z2}/routes.json`
  （Manual-C4 2D 结果，已逐条验收）。
- 代码：`four_side_1024/manual_c4/structured_layer_routing.py`（几何构造、可行性
  扫描、装配、payload/指标）、`structured_layer_plots.py`（图）、
  `structured_comparison.py`（对照表）。
- 搜索中间结果已固化在 `_work/`（各阶段 feasibility/params/checkpoint JSON），
  可按阶段重跑；A 的最终装配链：`_work/A_*`，B：`_work/B_*`。
- 权威验收：`structured_layer_routing.validate_payload(payload, v4_root=...)`；
  A 用 `phase2_2d` identity，B 用交换行后的 identity root（`_work/B_identity_root`）。

## 约束口径

板面 150×150 mm；R=15 mm（所有圆弧）；波导宽 0.05 mm；非豁免中心线净空
0.08 mm；接口高度 row1 z=0 / row2 z=0.5；L2/L3/L4/L5 = 1.0/1.5/2.0/2.5 mm；
端口位置与出入射方向固定；C4 严格四重旋转、四元组原子提交；升降只在二维直线段、
每条最多一次上升+一次下降；完整 XYZ 碰撞检查。层高为探索性参数，3D 验收为
exploratory PASS（formal_acceptance=false），不代表制造工艺正式验收。

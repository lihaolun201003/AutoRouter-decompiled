# 空间分组式 U 形线束三维布线优化（Manual-C4，2026-10-23）

基于 Manual-C4 动态优化 V2 的 1024/1024 布通结果，把 **64 个同边 U 形 C4 四元组（共
256 条波导）** 重构造为"延长直线 + 目标层圆弧"的空间分组式三维线束，其余路线保持原样。

## 目标层分配（固定，不因交叉数优化而改变）

| 线束 | C4 group | 条数 | 目标层 | 物理高度 |
|---|---|---:|---|---:|
| z1 四边中间 U | 20–35 | 64 | L2 | 1.0 mm |
| z2 第一组四角 U | 144–159 | 64 | L2 | 1.0 mm |
| z2 第二组四角 U | 160–175 | 64 | L3 | 1.5 mm |
| z2 四边中间 U | 176–191 | 64 | L4 | 2.0 mm |

合计 256 条 / 64 个四元组；L5 保留给其他线路避让。

## 新 U 几何

```
端口 → 延长入口直线(base z) → S 形上升 → 目标层 90°圆弧 + 中间直线 + 90°圆弧
     → S 形下降 → 延长出口直线(base z) → 端口
```

- 入口/出口直线长度、升降窗口（rise/fall 沿路径位置）为连续可优化变量；
- 目标层主圆弧深度 D（弧起点到板边距离）按束内嵌套顺序"外深内浅"分配，
  同层 16 条 U 保持有序嵌套、平行、间距 ≥ 净空；
- 每个四元组由一条代表路径 + 精确 90/180/270° 旋转生成，四条联合检查、原子提交；
- R=15 mm，圆弧只允许 90°（升降 S 曲线除外），升降只在二维直线段，每条 ≤1 升 1 降。

### 失败瓶颈与局部重路由（明确记录）

- 仅修改 U 时，z2 第二组四角 U 的 **group 167**（目标 L3）无法实现：其四个方向的
  U 高圆弧/高直线必须落在 z=1.5 mm 平面，而 V2 中非 U 的 C4 四元组 **group 11**
  （z1 对边，route_id 12/231/232/29）已被抬到 L3，其中两条长直线与 group 167 的
  端口出发直线在同一物理平面共线（x=142.375 / y=142.375 等），任何 (a, D) 都无法
  避免同层冲突 → 失败原因："被其他非 U 路线阻挡（L3 同层共线冲突）"。
- final 变体按任务允许的"独立局部重路由阶段"，把 group 11 整体重新抬升到 L5
  （z=2.5 mm，2D 拓扑/端口/连接不变，`a_in=64, a_out=48`），释放 L3 后 group 167
  可布。该修改逐条记录于 `u_layer_assignment.json.modified_non_u_routes` 与
  `validation.json`，并与 u-only 结果分开比较（上面的对照表）。

## 约束口径

板面 150×150 mm；R=15 mm；波导宽 0.05 mm；非豁免最小中心线净空 0.08 mm；
row1 z=0 / row2 z=0.5 mm；端口位置与入射方向固定；严格 C4 四重旋转、四元组原子提交；
升降只在原二维直线段、圆弧内部禁止升降、每条最多一次上升/一次下降；交叉统计跨全部
物理高度按唯一 (route_id_a, route_id_b) 去重。L2–L5 层高为探索性参数，三维几何 PASS
（exploratory）不等同于制造工艺正式验收。

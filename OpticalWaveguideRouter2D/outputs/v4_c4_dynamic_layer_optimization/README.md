# V4-C4 三维优化 V2 — 动态换层与局部重调度

> **发布校验说明（2026-10-22）**：最终状态以 `after/routes_l3d.json`、`after/validation.json` 及恢复阶段后的主指标为准：**49,992** 个全局唯一交叉线路对、**89** 个抬升组、**712** 次升降、**20** 个接受动作。`summary.json` 中 `pair_count=51,788`、`version/layout_version=14`、`retry_actions=0` 等旧别名属于恢复前状态。部分优化后路由记录采用紧凑 schema，可由 V4 的 route_id 映射及 `after/layer_assignments.json` 补齐身份与组信息；动作中的线路对列表仅为截断样本，不能直接重放完整差集。最终验收文件位于 `after/validation.json`；2400 s 是所记录主阶段预算，总耗时包含后续恢复阶段。详见 [本次上传校验清单](../../../UPLOAD_MANIFEST_20261022_layer_studies.json)。

输入基线：**V4-C4 层间距对照实验 B 组（0.50 mm）**已验收三维结果，1020/1024 布通、严格 C4。
本轮不重新做二维布线、不修改 L2–L5 层高，只对已抬升四元组做动态重调度 / 双组联合重调度 / 失败组重试。
唯一交叉指标口径：跨所有物理高度去重后的 `(route_id_a, route_id_b)` 唯一线路对。

另：共尝试双组联合调整 **65** 次（成功 1 次）；单组/重试阶段共记录 **127** 条真实 3D 碰撞拒绝
（含 125 条 true_3d_clearance、2 条重试拒绝）；每次接受动作均记录动作前后全局唯一交叉对数量；
所有接受动作在提交前都经过独立 `l3d.validate_l3d` 全量校验（避免提交后才发现碰撞）。
运行参数：R=15 mm，层高 L2–L5 = 1.0/1.5/2.0/2.5 mm，总预算 2400 s，总耗时约 3054 s（含恢复阶段）。

| `figures/after_3d.png/.svg` | 优化后完整三维图 |

实现：`four_side_1024/v3c4/dynamic_opt.py`（动态重调度引擎）与 `dynamic_run.py`（运行/验收/图）。
硬约束：不改变原二维 XY/端口/连接；升降只允许在原路径直线段，圆弧内禁止升降且整段恒定 Z；
每条路线最多一次上升+一次下降；四元组旋转+联合 3D 检查+原子提交；唯一交叉对必须严格减少；
提交前调用独立 3D 验证器。L2–L5 高度为探索性工艺假设，几何 PASS 不等同于正式制造验收。

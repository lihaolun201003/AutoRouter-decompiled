# gdspy is NOT listed here on purpose.
#
# gdspy 1.6.13 declares gdspy/clipper.cpp as a mandatory extension and PyPI
# publishes no Windows wheel for it, so a plain `pip install gdspy` needs a C++
# toolchain.  When none is available, run:
#
#     python tools/install_gdspy.py
#
# which installs the unmodified gdspy source together with a pure-Python
# gdspy/clipper.py fallback.  The fallback is never reached by this project:
# FlexPath(..., gdsii_path=True) + GdsLibrary.write_gds do not use polygon
# clipping.  See docs/migration_report.md.

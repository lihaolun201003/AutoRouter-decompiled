# V2 五层 2.5D 局部抬升双方案对照实验（A：保留 Short-S / B：纯正交 90°）

本报告对应代码：`OpticalWaveguideRouter2D/four_side_1024/fsd25d/`
（`path3d.py` 三维路径与 S 曲线、`world25d.py` 分层 2D strict 索引与真三维净空、`router25d.py`
增量抬升布线、`run25d.py` 运行器、`validate25d.py` 独立三维验收、`plots25d.py` 绘图、
`summarize25d.py` 统计汇总、`extra_metrics25d.py` 交叉指标）。
交付目录：`outputs/four_side_1024_v2_25d_v01/`（新建，未覆盖 752 / 262 两个冻结结果）。

## 0. 摘要

| 项 | 方案 A（保留 Short-S） | 方案 B（纯正交 90°） |
|---|---|---|
| 原二维基线 | **752 / 1024**（73.4%） | **262 / 1024**（25.6%） |
| 3 层 2.5D | **788 / 1024**（+36） | **342 / 1024**（+80） |
| 5 层 2.5D | **820 / 1024**（+68） | **383 / 1024**（+121） |
| 5 层相对基线 | +9.0% | **+46.2%** |
| 抬升线路 / 升降次数（5 层） | 68 条 / 136 次 | 121 条 / 242 次 |
| 实际三维交叉（2D 平铺 → 实际，5 层） | 104,076 → **87,279**（消除 16,797） | 34,091 → **11,138**（消除 22,953） |
| 三维最小中心线间距（5 层） | **0.08039 mm** | **0.09112 mm** |
| 完整三维最小曲率半径（5 层） | **39.9999997 mm** | **39.9999997 mm** |
| 独立三维验收（3/5 层全部） | **PASS（8 类违规计数全 0）** | **PASS（8 类违规计数全 0）** |
| 5 层相对 3 层增益 | +32 条 | +41 条 |

**一句话结论**：五层局部抬升**能显著救回一部分二维失败线路**（A +68、B +121），并把纯 90° 方案
从 262 提升到 383（+46.2%）；但它**不是万能的**——大量线路的瓶颈不在层数，而在"连二维 XY 候选都
没有"（A 42 条、B 426 条）以及接口层升降段的净空约束（A 162 条、B 215 条有候选但无法抬升）。
两种模型下 5 层都优于 3 层，但增益已呈边际递减。纯 90° 方案在几何规整性上明显更好，保留
Short-S 方案则在布通率上依然遥遥领先（820 vs 383）。

## 1. 实验目标与两组二维基线

| 方案 | 二维几何模型 | 二维基线 | 冻结来源 |
|---|---|---|---|
| **A** | D56：直线 + 90° 圆弧 + 非 90° Short-S | **752/1024**（z1 508 + z2 244） | `outputs/four_side_1024_v2_candidate_rr_v01/planes/V2/BEST` |
| **B** | 仅水平/竖直直线 + R40 完整 90° 圆弧（无 Short-S、无斜线） | **262/1024**（z1 128 + z2 134） | `outputs/four_side_1024_v2_ortho90_v01/planes/V2/ORTHO90` |

- 两个 2D 基线均已通过冻结独立 strict 验收，本实验**不修改**其任何二维几何。
- 保持不变的物理参数：V2 连接 CSV（SHA256 `49dd9e89…3915e`）、真实 2×16 双高度接口
  （z1 平面接口 z=0，z2 平面接口 z=0.5 mm）、板面 150×150 mm、波导宽度 0.05 mm、
  边缘间距 0.03 mm（中心线净空 0.08 mm）、R=40 mm、strict 交叉策略。
- 本轮**唯一新增自由度是高度**；不实现 Native 3D 联合寻路，也不改变两组各自的 XY 几何模型。

## 2. 五层空间模型与 2.5D 几何

### 2.1 层高与接口

| 层数 | 层高 z（mm） | 接口层 |
|---|---|---|
| 3 层 | 0, 0.25, 0.5 | z1 → 第 0 层（z=0）；z2 → 第 2 层（z=0.5） |
| 5 层 | 0, 0.125, 0.25, 0.375, 0.5 | z1 → 第 0 层（z=0）；z2 → 第 4 层（z=0.5） |

所有路线从原始接口高度出发、回到目标接口高度；可以局部上升、在其它高度传播、再下降。
中间层由两个平面共享（z1 上升与 z2 下降可在同一高度相遇），因此**不同层之间的冲突必须真实检查**。

### 2.2 升降曲线（S 曲线）的解析定义

升降段是**竖直平面内的两段 R=40 mm 圆弧**构成的 S 曲线，水平方向沿所在直线段。对高度差 `Δz`：

```
θ = acos(1 - |Δz| / (2R)),   footprint = 2R·sinθ,   总弧长 = 2R·θ
```

- 水平投影是直线段 → 不改变方案 A/B 的 XY 几何模型（方案 B 的纯 90° 限制仍作用于 XY 投影）；
- 起终点切向水平、与相邻平坦段相切 → 整条三维路径 **G1 连续**；
- 两段圆弧曲率均为 `1/R = 1/40 mm⁻¹` → 完整三维路径 **最小曲率半径 = 40 mm**。
- 升降段只允许放在水平/竖直直线段上（若放在 90° 圆弧上，XY 曲率与高度曲率叠加会破坏 40 mm 半径约束）。

### 2.3 一条路线的 2.5D 组成

路由数据中每条成功路线由按二维路径顺序排列的 5 段组成：

```
flat(接口层) → transition(升) → flat(中间层, 传播) → transition(降) → flat(接口层)
```

未抬升的路线只有一段 `flat`。接口层前后的平坦段必须满足该层的全部 2D strict 规则；
传播段的平铺 2D strict 规则由该层（可能有两个平面混合）的精确索引检查。

## 3. 算法

1. **基线保持**：两组已验收 2D 布局原样作为"接口层平坦路线"放入 2.5D 模型；
2. **失败路线重试**：对 2D 失败但**仍有 XY 候选**的路线
   （方案 A 230 条 = z1 4 + z2 226；方案 B 336 条，全部 z2），复用原有二维候选库：
   - A：`v2opt.candext` 的 D56 候选族（含 Short-S）；B：`v2opt.ortho90` 的结构族 + 精确 LP 多弯纯 90° 候选；
   - 每个候选先试"接口层平放"（该层 2D strict 通过即接受）；
   - 再试"抬升"：拆成 5 段，遍历可用中间层 × 2~3 种升降位置变体，检查三个平坦段的层内
     2D strict 合法性 + 升降段与所有已布路线的真三维净空（≥0.08 mm）；
3. **多轮 + 有界局部拆线重布**：3 轮 pass（第 2/3 轮使用不同升降位置变体）后，
   对仍失败的路线执行 rip-up-and-reroute（最多撕掉 2 条已抬升路线，只有净增才提交）；
4. **两组完全一致的搜索预算与验收规则**：候选评价预算 400/路线/轮（`--budget 400`）、
   `passes=3`、`--flat-probe 12`、R&R `rounds=2 / targets=64 / rip=2`，
   同一批候选来源与同一独立 3D 验收器。实际配置见每个 run 的 `run_summary.json`。

**"没有二维候选"的路线单独统计**：2D 阶段就生成不出任何 XY 候选的路线
（A 42 条；B 426 条 = z1 384 + z2 42）不会被"抬升"假装修复，在结果中单独列为 `no_2d_candidate`。

## 4. 独立三维验收（不把 2D PASS 当作 3D PASS）

`fsd25d/validate25d.py` 是**独立实现**：不 import 路由器几何代码（`router25d/world25d/path3d`），
只复用冻结的 `fslw.validate_fslw` 作为同层 2D strict 权威；从 `routes_25d.json` 的原始参数
**独立重建**每条三维中心线。检查项目（全部必须为 0 违规）：

1. parts 结构 / 相邻段三维端点重合（≤1e-6）/ `mode` 与段模式一致；
2. 端口：起终点 z 等于接口高度、XY 与 V2 端口一致、切向一致（≤1e-6）、z 向切向为 0；
   V2 端口 CSV / SHA256 身份核对；
3. XY 几何模型：B 平坦段只允许轴对齐直线 + R40/90° 弧；A 允许 D56 图元；
4. 曲率：三维路径 0.02 mm 采样最小外接圆半径 ≥40 mm（容差 0.1%），并解析检查 S 曲线参数与圆弧；
5. 真三维净空：任意两条路线中心线最小距离 ≥0.08 mm；同层合法 strict 交叉只在其交叉窗口内豁免；
   **所有 transition 参与的对全部真三维计算，无任何"不同层忽略"**；
6. 分层 2D strict 审计：每层所有平坦段用冻结 `audit_route_pairs(policy='strict')` 复核，violations 为空；
7. 板界（中心线离边 ≥0.025 mm）与自净空（自身非相邻部分 ≥0.08 mm）。

最终四个 run 的验收结果（`validation/all_validation.json`）：**全部 PASS**，
8 类违规计数（violations / structure / port / xy_model / curvature / clearance / layer_2d /
self_clearance / board）全部为 0；全局最小 3D 间距 0.080390234 mm、全局最小曲率半径 39.9999997 mm。

## 7. 最终回答

### Q1. 保留 Short-S 与纯正交 90° 两种模型，在五层局部抬升后分别能布通多少条？

- **A（保留 Short-S）：820 / 1024（80.1%）**，比二维基线 752 增加 **68 条**；
  其中 z1 = **512/512（补满）**、z2 = 308/512。
- **B（纯正交 90°）：383 / 1024（37.4%）**，比二维基线 262 增加 **121 条**；
  其中 z1 = 128/512（其余 384 条连二维候选都没有）、z2 = 255/512。
- 两组所有 820/383 条路线均通过**独立真三维验收**（曲率、端口切向、三维净空、分层 2D strict 全部 PASS）。

### Q2. 哪种布线更加规整？

**纯正交 90°（方案 B）明显更加规整**：其平坦段 100% 由轴对齐直线 + 恰好 90° 的 R40 圆弧组成
（非 90° 弧 0、斜线 0）；而 A 保留了 1,042 段非 90° Short-S 弧（视觉上表现为"斜向大弧"）。
两者抬升段的几何完全相同（R40 平滑 S 曲线），差别只在 XY 投影的构图规则。
但规整性的代价是布通率：B 只有 383 条（37.4%），A 有 820 条（80.1%），相差 2.14 倍。

### Q3. 五层是否足以显著改善拥塞？

**部分显著，但不足以解决拥塞**：
- **对可抬升的二维失败线路效果显著**：A 救回 29.6%（68/230）、B 救回 36.0%（121/336）；
  纯 90° 方案相对基线提升 46.2%，实际三维交叉比"全压回接口层"减少 67.3%（22,953 个）；
  A 方案补满 z1（512/512），并让实际三维交叉保持在接近基线的水平（87,279 vs 86,141）而多布 68 条。
- **对另两类失败无效**：① 无二维候选的线路（A 42、B 426，其中 B 的 384 条 z1 为几何不可达）；
  ② 有候选但接口层附近升降净空不足的线路（A 162、B 215）。这两类占剩余失败的大头。
- **3 层 vs 5 层**：5 层比 3 层多救回 A +32、B +41，说明增加高度数量**确实有效但边际递减**；
  单靠继续加层不会把 1024 布满，需要更灵活的 3D 路径自由度（如斜向/连续升降、端口附近变高度）
  或放宽 R/接口约束，才能进一步改善。

## 8. 结论与建议

1. 2.5D 局部抬升是**低成本、高收益**的攻击方向：不改变已验收布局，只在接口层附近加平滑升降，
   即可让 A 从 752 → 820（+9.0%）、B 从 262 → 383（+46.2%），且全部通过独立三维验收。
2. 高度自由度对**稀疏基线（B）相对收益更大**，对**接近饱和的 A 绝对收益有限**（但补满了 z1）。
3. 5 层优于 3 层（A +32、B +41），但 3→5 的收益小于"允许抬升"本身；继续加层之前，
   应优先解决**接口层升降净空**与**二维 XY 候选缺失**两个瓶颈。
4. 若最终目标是 1024 全布通，2.5D 局部抬升不够；建议下一轮做 **Native 3D 联合寻路**
   （XY 与 z 同时搜索、允许更多升降/斜向自由度，并保留 R40 与三维净空约束），
   本轮结果可作为其基线（A5=820、B5=383）。
5. 从工程/UI 角度，**A 方案（Short-S + 局部抬升）**是当前最优交付；**B 方案**适合作为
   "高规整度"备选（383 条），其几何形态远优于 A，但布通率只有 A 的 47%。

## 10. 局限

1. **2.5D 模型是"单次升降"**：每条抬升路线只有"一段平 → 升 → 一段平 → 降 → 一段平"，
   不支持多次升降/在端口附近变高度；因此部分本可布通的线路被判不可行（尤其 A 的 162 条、
   B 的 215 条"有候选但抬升失败"）。
2. **XY 候选完全复用二维库**：没有为 2.5D 重新生成"允许与已有线路二维冲突"的专用 XY 候选，
   失败路线若二维候选本身与接口层基线冲突，抬升只有在升降位置躲开时才可能成功。
3. **接口层升降净空保守**：升/降 S 曲线经过 z≈0 或 z≈0.5 附近时必须与同层路线保持 0.08 mm
   真三维净空，这等价于"不能在接口层附近跨越其他线路"，是 A/B 两类失败的主因之一。
4. **不修改已成功线路的高度**（任务要求优先"加入此前未成功的线路"），因此基线的 86,141 / 8,597
   个二维交叉大多数保留；若允许抬升已有线路，交叉数还能进一步下降（未来工作）。
5. 搜索结果与候选顺序/预算相关；我们做了 3 轮 pass + 有界 R&R，R&R 在 A/B 上均无净增益
   （与既有二维实验的饱和现象一致），不能证明是全局最优。
6. 五层/3 层的 0.125/0.25 mm 层间距是仿真假设，不代表工艺已确认；所有结论仅在该模型内成立。

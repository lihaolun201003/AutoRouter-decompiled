# 1024 通道四边单层二维 D56 光波导布线优化实验报告

本报告对应目录 `OpticalWaveguideRouter2D/outputs/four_side_1024_d56_optimized/`。
所有数字均来自本机真实运行与独立几何校验（`four_side_1024/d56/validate_d56.py`），
不是估计值，也不引用历史实验的数字。

## 1. 结论摘要

| 方案 | 路径几何 | 验收口径 | 布通数 | 布通率 | 对边/邻边 |
|---|---|---|---:|---:|---|
| **Legacy 80**（历史基线） | D56 正交 + R5 弧 | 历史 `clearance/sin(angle)` 交叉窗 | 80 | 7.81 % | 24 / 56 |
| **D56 Optimized**（本轮） | **D56 正交 + R5 弧（未改）** | **精确交叉区边界**（见 §5） | **467** | **45.61 %** | 53 / 414 |
| D56 Optimized，历史口径对照 | D56（同上） | 历史 `clearance/sin(angle)` 交叉窗 | 72 | 7.03 % | 10 / 62 |
| General 526（历史参考，非 D56） | Dubins/自由曲线 | 历史交叉窗 | 526 | 51.37 % | 490 / 36 |

**改进结论（真实、可复现）**：

1. 保持 D56 弯曲几何完全不变（仅正交直线 + 固定 R=5mm 圆弧 + 原 AutoRouter 小位移短 S
   公式），把布通数从历史 80 条提升到 **467 条（+387，×5.84）**，半径 5mm、波导宽 0.05mm、
   边缘间距 0.125mm、单层 `layer=0`、连接关系与端点坐标全部未改。
2. 提升的**主要来源不是布线顺序**，而是 Phase 1 诊断出的两个实现缺陷：
   (a) 历史交叉区公式 `clearance/sin(angle)` 对"圆弧参与交叉"是**欠豁免**（under-exempt），
       把大量 D56 合法几何判成间距违规；(b) 邻边只允许固定 L/固定 `x=145` 三弯模板、
       对边只允许固定轨道扫描。只改顺序（消融 A）最多到 437，顺序+候选族到 467。
3. **在历史交叉口径下，D56 几何本身的上限接近 80 条量级**：同一套新算法、同样候选族与
   最优顺序，改用历史 `clearance/sin(angle)` 口径后只有 72 条（甚至低于历史 80 条，
   因为历史 80 条用了 600 s / 900k 次评价、我们只用了 318 s / 260k 次评价）。
   这直接回答了"为什么原版只能布通 80 条"：**主因是验收公式对曲率的数值欠豁免，
   不是布线策略本身**。
4. 本轮**没有**用 F56 自由弯角、斜线段、Dubins、贝塞尔/样条，也没有缩小半径或放松间距；
   所有路线经独立校验器逐条确认 D56 几何合法（467/467）。
5. 剩余 557 条未布通：对边 459 条（NS 228 + EW 231）、邻边 98 条（ES 85 + SW 13）。
   它们是**边带/角区结构拥塞**与"固定端点 + R=5"几何共同造成的，不是预算不足
   （评价次数 172k/172k，运行 169.6 s，远未触及时间上限）。

## 3. 未修改的传统 D56 弯曲几何

新增候选族**全部**由以下三种图元构成，与 `wiring_rect_826.py` / `wiring_bend_826.py`
的 D56 模型一致：

1. 水平/竖直直线段；
2. 半径恰为 5.0 mm 的 90° 转角圆弧（切点距角点 R，圆心在角点两方向单位矢量和处，
   由 `legacy_geometry._orthogonal_quarters` 构造，与旧公式逐项一致）；
3. 原 AutoRouter **小位移短 S** 公式：`theta = acos(1 - d/(2R))`、纵向偏移 `R sin(theta)`，
   两段半径仍为 R 的圆弧直接相连（中间水平段长度为 0），仅用于 `0 < d < 2R` 的对边连接；
   `d = 0` 退化为直线；`d ≥ 2R` 为两段 90° 圆弧 + 中间直线。半径从不缩小为 `d/2`。

独立校验器对每一条交付路线检查（467/467 全部通过）：
无斜向直线段、无 F56 自由弯角、圆弧半径 == 5.0±1e-9、`sweep` 仅 ±90° 或短 S 的 `theta`
（且短 S 必须成对、`d = 2R sin theta`）、端点固定、出入射方向正确、G1 位置与切向连续、
`layer=0`、描边后在板内、无自交/自重叠。

## 5. 交叉区口径：历史近似与精确实现（方法学核心）

历史实现（80 与 526 基线都用它）把交叉豁免窗取为
`half = clearance / sin(angle) + 2*sagitta`（沿两条曲线各取一段）。
该公式**只对两条直线精确**：沿直线移动 `s` 时到另一条直线的垂直距离恰为 `s sin(angle)`。
当交叉涉及圆弧时，弧的切向在移动中旋转，同样弧长对应的距离增长**更慢**，
真实"距离 < clearance"的区间比公式给出的更长，即历史口径**欠豁免**。

实测（本轮可复现）：CSV 原生直接 L 路径中，弧-线交叉角 61.6° 时历史窗口边界处
几何距离为 **0.173936 mm**（< 0.175，短 1.06 µm）；26.5° 浅角交叉短 **13.5 µm**。
对 508 条直接 L 两两检查：历史口径报 **6692 对违规**，而按精确交叉区计算只有 **209 对**
（96.9 % 是数值假冲突）。这一条同时解释了：① 为什么 80 条基线中 76 % 的候选评价
以 `spacing_pairs` 失败；② 为什么 CSV 明显是按"直接 L 拼花"设计的（256/256 条邻边
y 线两侧水平段间隔恰为 10.000 mm = 2R）却几乎全部被拒。

**本轮处理（明确记录，不隐藏）**：

- 交付主口径 = **精确交叉区边界**：横向交叉恰好豁免"相交的那一对 primitive"，
  不相交的 primitive 对仍严格检查 0.175 mm；重叠、切触、同 primitive 对二次交叉、
  交叉窗互叠全部拒绝。半径、宽度、间距、单层约束、端点坐标**一律未改**。
- 同时给出**历史口径敏感性**：同一算法改用历史公式时布通 72/1024；
  交付解在历史口径下有 8919 对"违规"，其距离短差为 **4.9 nm ~ 51.1 µm（中位 3.0 µm、
  均值 6.9 µm；>50 µm 仅 1 对、0 对 > 75 µm）**，最小中心距 0.123935 mm，
  0 重叠 / 0 切触 / 0 半径 / 0 板界 / 0 斜线 —— 全部位于交叉窗边界，
  属于同一个近似误差，不是物理间距违规。
- 交叉角分布显示交付解几乎没有小角交叉：57 029 个交叉中 47 135 个在 75–90°，
  <10° 仅 9 个，因此"精确交叉区"的实际豁免长度约 0.18 mm 量级，物理上是一个正常
  的直角交叉单元，不构成"用长距离近距平行段换取布通"。

## 6. Phase 1：80 条基线为什么只能布 80 条（详见 `d56_1024_failure_diagnosis.md`）

量化诊断（可复现脚本在 `scratch/diagnosis/`）：

1. **坐标变换无误**：6 个有向对的 canonical 端点/入射方向往返最大误差 1.9e-14 mm、方向误差 0。
2. **`noCross` 与端口次序规则**：只拒绝 37 142 / 5 241 次（占 547 948 次轨道扫描的 7.8 %），
   不是主因。
3. **邻边固定模板不足**：历史三弯模板末端竖线固定 `t2 = 145 mm`，当源端 canonical x > 135 时
   800 条轨道全部 bend 失败（每邻边组约 39 条路线因此必失败）。
4. **主因是交叉区欠豁免**：429 559 次几何评价中 327 826 次以 `spacing_pairs` 失败，
   而其中绝大多数在精确实现下合法（见 §5）。
5. **容量**：四边各 512 端口、pitch = clearance = 0.175 mm；每个边带内没有额外平行车道，
   连接器间隙区每侧约 285 条备用车道；对边 U 型的"车道长度需求/供给"约 40.75 %，
   **全局车道长度未饱和**，瓶颈是边带/角区被 100 % 占满 + 交叉区口径。
6. **直接 L 的精确最大独立集 = 299/508**（209 个冲突对互不相交），任何顺序的贪心都恰好 299；
   这与实测"邻边 only（含 Z3 绕行）可布 385/512"一致：**直接 L 单独不够，必须扩充候选**。

## 7. 布线顺序对照实验（Phase 2）

同一 CSV、同 R/间距/碰撞判定、同候选集合、同评价预算（≤900 次/路线），只改顺序：

| 顺序策略 | 布通 | 对边 | 邻边 | 说明 |
|---|---:|---:|---:|---|
| A 原固定顺序 SW→ES→NW→EN→NS→EW | 437 | 67 | 370 | 只改顺序时最好的"原序" |
| B 对边优先 NS→EW→EN→ES→SW→NW | 358 | 324 | 34 | 对边优先在 D56 下**不利** |
| C 对边优先 + 邻边动态拥塞排序 | 359 | 325 | 34 | 同 B |
| D 全部按预计拥塞排序 | 315 | 218 | 97 | 最差 |
| E 邻边优先 EN→ES→SW→NW→NS→EW | 428 | 39 | 389 | 邻边刚性 L 必须先布 |
| **E′ 邻边优先 NW→EN→SW→ES→NS→EW（最终）** | **467** | **53** | **414** | 最优 |

**结论**：526 自由曲线实验里"对边优先"的优势**不能迁移到 D56 几何**。D56 下邻边连接是
**刚性单 L**（两个端点决定全部几何），一旦对边/其它邻边先占位就几乎没有回旋空间；
因此必须**先布邻边、再布对边**，且邻边内部的四个角组顺序对结果影响 30~100 条
（A/E 437/428 → E′ 467）。这与 Phase 3/4 的候选与索引改进共同贡献了 80 → 467 的提升。

## 9. 邻边连接为什么困难（几何分析）

邻边连接（E→S、S→W 等）在 canonical 系中是**单 L**：竖直臂在源端 x、水平臂在目标端 y，
两个臂的位置都由端点唯一决定，转角圆弧的位置也随之固定。困难来自三处：

1. **端点 comb 与 clearance 同为 0.175 mm**：S/N 边 512 条竖臂、E/W 边 512 条横臂在
   连接器内以 0.175 mm 间距排列。L 型转角圆弧的切点落在 `px ± 5 mm`，这些位置与 comb
   相位无关，因而经常落在距某条既有竖臂 0.0875 mm 处（< 0.175）→ 固定 L 直接违规。
2. **转角圆弧扫过的 5×5 mm 区域与对边竖臂/横臂冲突**：D56 不允许缩小半径，圆弧必须完整
   扫过 5 mm；这使邻边连接在边带附近占用一个"方角"，而对边连接的固定竖臂恰好从同一边带
   出发，两者在 0.175 mm 阈值下几乎必然相遇。
3. **Z3 绕行只能移动末端转角**：水平臂仍在固定 y，竖直臂仍在固定 x，只能通过增加折返
   把转角挪开；一旦同一角区已密布对边竖臂，绕行候选也很难找到 0.175 mm 净空。

因此邻边是"固定几何 + 严格 clearance + 固定 R"共同限制的**结构难点**，不是候选不够多。

## 10. 当前限制：算法问题还是物理几何问题

**两者都有，但以结构/几何限制为主**，证据如下：

- 算法侧（已改进、仍有空间）：顺序仍有 30~100 条的差异（A/E 437/428 → E′ 467）；
  Z3 候选只覆盖 3 弯，未实现 5 弯以上；Rip-up 未能在全局拥塞下奏效。
- 结构/几何侧（本轮实测的硬限制）：
  1. 对齐的端点 comb 间距恰等于 clearance ⇒ 每条"边带"内无多余平行车道；
     四边合计 2048 条引出臂已把边带占满。
  2. D56 固定 R=5 mm 的转角必须在角区完整扫过 5×5 mm；邻边与对边的固定臂在同一角区
     交叉，能同时满足 0.175 mm 净空的组合很少。
  3. 对边:邻边 = 512:512 时，交付解实现 **53 对边 + 414 邻边**；纯对边 alone 可布 **324**，
     纯邻边 alone 可布 **385**（§6b）。两者之和 709 远大于 467，说明**两类连接争用同一批
     角区/边带净空**，这是单层共享面积的拓扑代价。
  4. 在历史交叉口径下同一算法只能布 72 条，说明若坚持历史近似公式，D56 几何在本题上
     基本不可用；这不是算法能解决的，属于验收口径的数值问题。
- 因此：**不能声称 1024 是算法可轻易达到的**；本轮给出的是"在严格 D56 几何 + 精确交叉区
  口径下，单层二维的实测可达 467/1024，并给出 53/414 的关系分解与结构证据"。

## 14. 后续三维算法可以解决什么问题

1. **角区/边带净空争用**：单层下邻边与对边必须共享同一批 5×5 mm 转角区域；
   三维可在 z 向把邻边引出与对边中继分层，直接消除第 9 节的 1/3 两类冲突。
2. **低角度与密集交叉**：本轮虽然 <10° 交叉只有 9 个，但 57k 个 90° 交叉仍需交叉单元；
   三维可用层间耦合替代同层交叉，减少交叉损耗与工艺风险。
3. **真实 2×16 双排端口扇出**：本轮仍用 `virtual_unfolded` 计算端点，真实双排端口到
   单层的耦合/扇出尚未设计；三维扇出可以按真实 (u,v) 端口位置逐通道展开。
4. **R=5 的刚性转角**：三维曲线（连续曲率波导）可在不减少层数的前提下放宽转角空间限制，
   但这属于新的几何模型，**不属于本次 D56 实验范围**。

## 15. 限制与诚实声明

- 本次仍是 `virtual_unfolded` 二维计算实验：**不是**真实 2×16 接头器件的可制造结论；
  9 mm 接头中心距与完整 MPO 外壳的机械冲突（60 对）与端口平面耦合问题依然存在。
- 交叉单元、间距、半径均为初版验证参数（0.125 mm 边缘间距、R=5 mm、0.05 mm 宽度），
  不是新玻璃工艺的最终指标；同层交叉的光学可行性需独立设计验证。
- **未达到 1024/1024**，也**没有**为了追求数字而改变模型、删除失败路线或缩小半径。
- 交叉区口径的差异在 §5 完整披露：交付主口径为精确交叉区；若评审要求沿用历史
  `clearance/sin(angle)` 公式，则本次结果为 **72/1024**，且报告给出该口径下 8919 对
  ≤51 µm 的数值短差清单（`scratch/validate_final*.json`）。
- 本报告所有"历史口径"数字与历史基线数字均来自各自 `statistics.json`；
  本方案的交叉数、长度、违规数均由独立校验器从解析几何重新计算，不用引擎内部计数器。
